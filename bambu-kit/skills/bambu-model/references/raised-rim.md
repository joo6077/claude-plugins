# 솟은 테두리 — 덧대고 깎기

컵 통 · 손잡이 홈 가장자리처럼 **벽 끝이 살짝 솟아 둥글게 말린 테두리**를 CadQuery 로 만드는 방법이다.
실측 출처: 책상 클램프 컵 도킹(2026-11-22 ~ 23, `cup_dock.py`). 테두리를 세 번 다시 만들었다.

## 1. 붙이지 말고 덧대고 깎는다

| 판 | 방법 | 사용자 반응 |
| --- | --- | --- |
| 1 | 둥근 관(원 단면)을 경로를 따라 이어 붙임 | 「그냥 선을 붙인 거 같다」 |
| 2 | S 자 단면 띠를 경로를 따라 이어 붙임 | 「선을 대는 게 아니라 튀어나오게」 |
| 3 | 벽 전체를 1.2 mm 덧대고 무늬 자리만 원래 면까지 깎음 | 「모양은 그게 맞아」 |

경로를 따라 붙인 띠는 단면을 바꿔도 폭이 일정한 덧붙임이라 벽에서 따로 논다. 회전체 통은 덧대기가 오히려 쉽다.

1. 바깥 단면을 솟을 높이만큼 키워 돌린다. 이음 · 목처럼 통에 붙는 몸체도 윤곽을 `offset2D(높이, "arc")` 로 같이 덧댄다.
2. 홈은 덧댄 몸체에서 먼저 자르고, 홈 모서리 둥글리기도 이때 한다. 안쪽 모서리는 그대로 남고 바깥 모서리는 3 단계 칼이 다시 깎는다.
3. 깎는 칼로 **무늬 자리**를 원래 면까지 깎는다. 남은 가장자리가 테두리다 — 홈 잘린 면이 그대로 테두리 끝까지 올라간다.
4. 무늬 홈은 마지막에, 테두리 폭 밖에서만 판다.

모양 해석이 갈리면 그리기 전에 묻는다. 위에서 내려다본 단면을 ASCII 그림 두 개로 보이면 한 번에 고른다 —
「덧댄 벽 + 계단 둥글리기」 와 「가장자리 끝만 말아 올림」 을 보였더니 사용자가 「가장자리만인데 가장자리 끝에서」 로 답했다.

## 2. 둥근 끝은 칼 단면에 넣는다

이 형상에서 CadQuery 오목 `fillet` 은 반지름 0.3 ~ 1.0 이 전부 `BRep_API: command not done` 으로 실패했다.
둥글리기를 나중에 하지 말고 **칼 단면**의 모양으로 만든다. 높이마다 칼 단면을 놓고 `cq.Solid.makeLoft(단면들, True)`(ruled — 단면 사이를 곧게 잇는다)로 잇는다.

단면의 각 점은 「원래 면 위로 남길 높이」 를 계산해 그만큼 바깥에 놓는다. `s` 는 홈 가장자리에서 무늬 쪽으로 간 거리, `fz` 는 위 · 아래 끝에서 들어온 정도(0 = 끝, 1 = 무늬 자리)다.

```python
# lip-height profile
def _smooth(x):
    x = max(0.0, min(1.0, x))
    return x * x * (3 - 2 * x)


def lip_height(s, fz, H=1.2, rn=1.2, ramp=3.0):
    """원래 면 위로 남길 높이. 홈 면에서 0 으로 시작해 반지름 rn 1/4 원으로 H 까지 오르고(홈 면 · 꼭대기 양쪽에 접한다),
    무늬 쪽으로 ramp 에 걸쳐 smoothstep 으로 0 까지 내려간다. 위 · 아래 끝 근처(fz 작음)는 통 전체가 솟은 채로 남는다."""
    nose = H if s >= rn else math.sqrt(max(0.0, rn * rn - (rn - s) ** 2)) + (H - rn)
    field = H if s < rn else H * (1 - _smooth((s - rn) / ramp))
    return min(nose, max(field, H * (1 - fz)))
```

- 처음에 쓴 식은 거꾸로였다 — 「깎을 깊이」 를 `fz` 로 곱하다가 무늬 자리(`fz = 1`)에서 홈 끝 0 ~ 1.2 mm 를 전부 깎았다. 결과는 둥근 끝이 아니라 **평평한 턱 + 수직 벽**이었다.
  STL 은 닫혀 있고 계약 측정도 전부 통과했다. 그림이 작아 두 번 놓쳤고, 4 절의 단면 실측으로 찾았다.
- 다른 몸체와 만나는 끝(이음이 등판과 만나는 곳)도 턱을 남기지 말고 오르막으로 만든다 — `max(높이, H * (1 - smooth(거리 / ramp)))`.

## 3. 칼을 만들 때 함정

| 함정 | 증상 | 대응 |
| --- | --- | --- |
| 단면마다 점 수가 다르다 | ruled loft 가 `BRep_API: command not done` | 각도 목록을 `set()` 으로 중복 제거하지 마라 — 높이마다 점 수가 162 · 163 으로 갈렸다. 같은 개수 · 같은 순서로 만든다 |
| 칼 면과 몸체 면이 겹친다 | 두께 0 조각 · STL 구멍 | 다 깎는 자리는 원래 면보다 0.08 mm 더 파고, 칼에서 원래 몸체(덧대기 전)를 빼서 되돌린다. 홈 쪽은 칼을 홈 면보다 0.6 mm 안쪽(홈 속)에서 시작한다 |
| 빨리 변하는 구간의 단면이 듬성하다 | 작은 **부스러기** 고체가 떨어진다 | 홈이 위로 벌어지는 구간 · 위아래 끝 근처는 단면을 0.5 mm 간격으로 촘촘히 넣는다 (듬성했을 때 0.03 mm³ 부스러기 4 개) |
| 합치기 · 깎기 함수가 가장 큰 고체만 남긴다 | 떨어진 **조각**이 조용히 사라진다 | 버리기 전 조각 수와 부피를 출력하고, 1 mm³ 넘는 조각이 있으면 멈춘다 |
| 같은 칼로 두 번 자른다 | 두 번째 `cut` 의 정리 단계에서 `BRep_API: command not done` | 같은 칼로 두 번 자르지 마라 — 홈은 덧댄 회전체에서 한 번만 자른다 |
| 상자 선택으로 홈 모서리만 고르려 한다 | 안쪽 면 모서리까지 154 개가 걸려 둥글리기 실패 | 먼저 둥글리고 깎는다 — 덧댄 회전체에서 홈을 자른 직후 둥글리고, 그다음 칼로 무늬 자리를 깎는다 (1 절 2 단계) |

## 4. 단면을 재서 확인한다

3D 확대 그림은 잘린 삼각형이 섞여 둥근 끝인지 턱인지 알아보기 어렵다. 높이 몇 곳에서 STL 을 수평으로 잘라, 홈 가장자리부터 둘레 방향으로 0.1 mm 간격으로 솟은 높이를 재서 단면 높이 표로 낸다.
기대 모양: 홈 끝 0 근처 → 둥근 끝 반지름 지점에서 H → ramp 끝에서 0. 이전 판과 새 판을 한 그래프에 겹쳐 그려 사용자에게 보이면 바뀐 점이 한눈에 보인다.

- 자르는 높이를 칼 단면 높이와 정확히 같게 잡으면 이상한 값이 나온다 — 0.3 mm 쯤 비켜 잡는다.
- 한 높이에서 잰 값만 믿지 말고 위 · 가운데 · 아래 세 곳 이상을 잰다. 세 곳 값이 같아야 칼이 고르게 깎인 것이다.
- 다른 몸체와 만나는 끝(이음 · 등판)도 같은 방법으로 잰다 — 수직 턱 1.2 mm 가 이 측정으로 드러났다.
