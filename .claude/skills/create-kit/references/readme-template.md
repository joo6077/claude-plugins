## 스킬

| 스킬 | 용도 |
|------|------|
| `/{kit-name}-guide` | {도메인} 코드/설정에 대한 원칙 기반 가이드 (가벼운 리뷰) |
| `/{kit-name}-audit` | {도메인}을 카테고리별 PASS/FAIL로 체계적 감사 |
| `/{kit-name}-{system\|init}` | 프로젝트 {도메인} 기반 세팅 ({구체적 산출물}) |

## 사용 예시

### 가이드 (가벼운 리뷰)
```
/{kit-name}-guide "이 {예시 대상} 괜찮아?"
```

### 감사 (체계적 검사)
```
/{kit-name}-audit <대상 경로>
```

### 초기 세팅
```
/{kit-name}-{system|init} [프로젝트 경로]
```

## 참고

- 이 킷은 **스택 무관**이다. 특정 프레임워크(예시 나열)에 종속되지 않는 범용 원칙만 다룬다.
- 구체적 구현은 각 프로젝트의 스택에 맞게 사용자가 적용한다.
- 원칙 출처는 모두 공식 문서, RFC, 학술 논문, 신뢰할 수 있는 엔지니어링 블로그에서 가져왔다.

- `infra-kit` — 인프라/DevOps 원칙 (12개 문서, 3스킬, 1에이전트)
