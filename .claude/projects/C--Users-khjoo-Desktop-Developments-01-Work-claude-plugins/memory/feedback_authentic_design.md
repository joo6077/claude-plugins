type: feedback
---

design-kaizen 진행 시 "AI스럽지 않은 디자인" 가이드라인을 리서치 범위에 포함할 것.

**Why:** AI가 생성하는 UI/UX는 과도한 균일성, 제네릭 컬러, 추상적 카피, 맥락 무시 등 특유의 패턴이 있는데 현재 design-kit/docs/design/에 이를 다루는 문서가 없음. 사용자가 직접 요청한 개선 방향.

**How to apply:** design-kit/docs/design/foundations/에 authentic-design.md(가칭) 리서치 문서를 작성하고, design-kaizen 사이클에서 이 문서를 기반으로 design-kit 스킬들의 Gotchas와 audit-criteria에 반영. 안티패턴 예시: 템플릿 반복 레이아웃, 무의미한 글래스모피즘, AI 특유 추상 문구, 과잉 장식, 브랜드/문화 맥락 무시, 과도한 대칭.
