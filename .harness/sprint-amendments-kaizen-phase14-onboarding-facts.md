## AM-01 — clarification (측정문 결함 신고 · 조건 문구 변경 없음)

**대상**: ER-03 의 1차 측정절
**원문**: `awk '/[Dd]eprecated/ && /\.p12/' docs/onboarding-kit/examples/fcm-ios-setup-guide.md` 결과 0 행

**실행 결과 (2026-08-13)**

| 시점 | 측정 결과 | 그 행의 실제 내용 |
| --- | --- | --- |
| 구현 직후 | **1 행** (`:62`) | "1차 출처가 이를 deprecated 로 표기하지는 **않으므로** 이 가이드도 그렇게 부르지 않는다" |
| 정정 후 | **0 행** | 해당 문장을 evidence 권고안 문구로 교체 |

**판정**: 원 측정문은 **행 단위 동시출현(co-occurrence) 휴리스틱**이라 `.p12` 가 deprecated 가
**아니라고 부정하는 문장**까지 위반으로 잡는다. 즉 걸린 행은 조건이 금지하려던 "단정" 이 아니라
그 반대였다 — **거짓 양성**이다.

**조치**: 계약 본문은 고치지 않는다 (write-once). 대신 evidence `phase14.md` §2 권고안
("`.p12` 를 deprecated 로 단정한 문구를 제거. '현행 가이드는 `.p8` APNs authentication key 를
안내한다' 정도로 낮추기")을 그대로 적용해 해당 문장을 다시 썼다. 결과적으로 **원 측정문을 문자
그대로 충족**하며, 우회가 아니라 근거가 요구한 방향의 정정이다.

출처 인식론에 대한 메타 서술(왜 강도를 올리지 않는가)은 애초에 **사용자용 셋업 가이드가 아니라
스킬 규칙의 자리**다 — 그 서술은 `references/search-strategy.md` §역방향 금지 에 남아 있다.

**다음 사이클 재사용 시**: 이 조건은 부정문을 통과시키도록 좁혀야 한다. 예를 들어 "❌ Deprecated"
박스 존재(이미 2차 측정절에 있음)와 단정형 술어를 함께 요구하는 형태로 쓴다. 동시출현만으로는
use-mention 을 구별하지 못한다.

## AM-02 — clarification (자기 검증 절차 결함 · 계약 무관 · 기록 목적)

**대상**: 계약 §회귀 게이트 "셸 이식성" 규약을 내가 스스로 위반한 사례

자기 검증 중 잔존 0 건을 확인하려고 아래 형태를 썼다:

```bash
SCOPE="a.md b.md c.md d.md"
grep -n 'AppDelegate' $SCOPE      # ← zsh 에서 단어분할이 일어나지 않는다
```

**실행 결과**: `ugrep: warning: a.md b.md c.md d.md: No such file or directory` 를 내면서
**모든 검사가 "0건" 으로 보고**됐다. zsh 는 unquoted parameter expansion 을 단어분할하지 않으므로
4 개 경로가 **파일명 하나**로 전달됐고, 파일을 한 줄도 읽지 않은 채 "잔존 0 건" 이 나왔다.

**판정**: 전형적인 **거짓 음성**이다. 경고를 흘려보냈다면 "사실 정정 완료" 를 증거 없이 보고할
뻔했다. `set -- <경로들>` + `"$@"` 로 바꿔 재실행하니 실제로는 hit 이 여러 건 있었고(전부
use-mention 으로 정당), 그제서야 판정이 성립했다.

**교훈 (다음 사이클 측정문 작성 규약)**:

1. 다중 경로는 변수 문자열이 아니라 `set -- …` + `"$@"` 또는 명시 인자로 넘긴다.
2. **"0 건" 을 주장하는 모든 오라클에는 양성 대조를 붙인다** — 반드시 잡혀야 하는 토큰을 같은
   명령 형태로 세어 0 이 아님을 먼저 보인다. 이번에 `grep -c 'APNs'` 를 양성 대조로 넣고서야
   앞선 0 건이 전부 무효였음이 드러났다.
3. 파일 인자를 받는 검사는 실행 전에 `[ -f "$f" ]` 로 존재를 확인하고, 아니면 즉시 비정상 종료한다.
