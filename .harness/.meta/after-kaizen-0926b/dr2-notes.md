## 결정

- 짝 목록이 NEW 로 낸 열다섯 가운데 열 개는 이름만 다른 기존 쪽이 이미 목차에 있어서, 새 이름으로 두 번째 쪽을 만들지 않고 기존 쪽을 원본에 맞춰 다시 썼다. 근거는 dca 묶음의 DC-9 매핑 결정(`dca-notes` 109~162 줄)이 이 열을 「짝: 기존 페이지」 로 정한 것이다.
- 같은 원본으로 쪽을 하나 더 만들면 원본 하나에 쪽 둘이 생겨 docs-site Gotcha 7 을 어기고, 있는 것을 다시 만들지 말라는 RE-02 에도 걸린다. 그래서 드리프트 도구의 덮어쓰기 매핑에 열 줄을 더해 도구가 기존 쪽을 짝으로 고르게 했다.
- 새 쪽 다섯 가운데 `research-log` 셋은 dca 결정표가 「페이지 없음이 맞음」 이라 적었지만, 사용자 결정 DC-1 이 같은 종류인 api 연구 기록을 새 쪽으로 만들게 했고 그 선례(`docs/api-kit/research-log.html`)를 따라 새 쪽으로 만들었다. dca 결정과 다른 점은 이것 하나다.
- tone-kit 의 `sources.md` 는 dca 결정표에 없는 원본이라 대응 쪽이 없었고, 목록이 NEW 로 짚었으므로 `docs/tone-kit/sources.html` 새 쪽으로 만들었다.
- react 설계 문서 여덟(`kit-design` 폴더)은 사용자 결정 UD-6 으로 2026-09-26 에 지금 스킬과 맞춘 판이다. 이번 쪽은 그 현행화된 판 전문을 옮겼고, 각 쪽의 현행화 기록 표도 그대로 들어 있다.
- `design-brief` 원본은 howto-kit 개요 쪽에 전문으로 옮겼고, 옛 개요가 담던 원본 코드 표시 34 개는 새 판에 모두 남았다.
- `feedback-schema` 원본은 YAML 이라 피드백 시스템 쪽에 키 41 개를 묶음별 키 표로 옮기고, 원본 예시 블록을 따로 싣고, 주석까지 든 원본 전문을 덧붙였다.
