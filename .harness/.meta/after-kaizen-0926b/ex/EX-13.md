## 2. 질문별 확인

### A. Variables 색 값은 OKLCH를 지원하는가?

원문 인용:

> “Color variables use color values with opacity, such as `#000000` at 80% opacity or `rgb(255, 205, 41)` at 100% opacity.”

출처: [Overview of variables, collections, and modes](https://help.figma.com/hc/en-us/articles/14506821864087-Overview-of-variables-collections-and-modes), 2026-09-26.

색 모델 목록 원문:

> “Figma allows you to see colors across five color models: Hex, HSB, HSL, CSS, and RGB.”

출처: [About color models](https://help.figma.com/hc/en-us/articles/360043042113-About-color-models), 2026-09-26.

용어를 구분하면:

- 공식 문서가 열거한 **색 모델**: Hex, HSB, HSL, CSS, RGB
- 공식 문서가 별도로 설명한 **색 프로필**: sRGB, Display P3
- OKLCH는 위의 색 모델 목록에 없음

저장소 주장:

> “Figma Variables는 OKLCH 미지원”

판정: **원문에 없음**

공식 도움말에서 “Variables do not support OKLCH”처럼 직접 선언한 문장은 찾지 못했습니다.

추론: 공식 문서가 사용할 수 있는 색 모델을 다섯 가지로 한정해 열거하고 OKLCH를 포함하지 않으므로, Variables UI에서 OKLCH를 직접적인 값 표현 형식으로 지원하지 않는다는 결론과는 부합합니다. 다만 이 추론을 공식 원문의 직접 단정처럼 적으면 근거보다 강한 표현이 됩니다.

### B. Variables REST API는 색을 어떤 형식으로 돌려주는가?

반환 필드 원문:

> “`valuesByMode` Map<String, Boolean | Number | String | Color | VariableAlias | VariableComposedColor>”

출처: [Variables REST API — Types](https://developers.figma.com/docs/rest-api/variables-types/), 2026-09-26.

`Color` 형식 원문:

> “An RGBA color.”

이어지는 필드 정의는 `r`, `g`, `b`, `a`가 각각 0과 1 사이의 숫자라고 명시합니다.

출처: [REST API — Property types](https://developers.figma.com/docs/rest-api/file-property-types/), 2026-09-26.

엔드포인트 응답 정의도 `valuesByMode` 값에 `Color`, `VariableAlias`, `VariableComposedColor`가 올 수 있다고 명시합니다. [Variables REST API — Endpoints](https://developers.figma.com/docs/rest-api/variables-endpoints/)

정리:

- 직접 저장된 원시 색: `{ "r": number, "g": number, "b": number, "a": number }`
- 각 채널 범위: 0–1
- 별칭이면 `VariableAlias`
- 색과 불투명도를 독립적으로 작성한 값이면 `VariableComposedColor`
- Hex 문자열이나 OKLCH 문자열로 반환된다고 적혀 있지 않음

저장소 주장: 해당 메모에는 REST API 반환 형식에 대한 별도 주장이 없습니다.

판정: **원문에 없음** — 비교할 저장소 주장이 없으며, 공식 원문상 반환 형식은 위와 같습니다.

## 3. 저장소에 반영할 문장 제안

- `Figma 공식 도움말은 사용 가능한 색 모델을 Hex·HSB·HSL·CSS·RGB로 열거하며 OKLCH를 포함하지 않지만, Variables의 OKLCH 미지원이라고 직접 단정하지는 않는다.`
- `Variables REST API의 원시 색 값은 0–1 범위의 r·g·b·a 필드를 가진 RGBA Color 객체로 반환되며, 별칭 또는 composed color일 수도 있다.`

## 4. 못 가져온 것 / 열린 질문

- “Figma Variables는 OKLCH를 지원하지 않는다”라는 정확한 직접 문장은 공식 도움말과 개발자 문서에서 찾지 못했습니다.
- 색 모델 목록은 Figma 색 선택기 전반의 문서입니다. 이 목록이 Variables 입력에만 적용된다고 직접 연결하는 문장은 확보하지 못했습니다.
- 공식 페이지는 정상적으로 가져왔으므로 `curl` 재시도는 필요하지 않았습니다.
