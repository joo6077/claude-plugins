# 쉬운 말 목록 (기계가 읽는 파일)

`~/.claude/hooks/check-plain-korean.sh` 가 답변을 내보내기 직전에 이 파일을 읽어 대조한다.
사람이 읽으라고 만든 문서가 아니라 검사에 쓰는 데이터다. 새 낱말에 걸렸으면 여기 한 줄 추가하면 된다 —
`~/.claude/CLAUDE.md` 를 늘리지 마라. 규칙이 길수록 안 지켜지지만 이 파일은 기계가 읽으므로 길어져도 괜찮다.

표 읽는 법:

- 1열 — 걸러낼 말. ` / ` 로 나누면 각각이 따로 검사된다
- 2열 — 대신 쓸 말. 걸렸을 때 이 문장이 그대로 안내로 나간다
- 3열 `검사` — `on` 이면 검사한다. `off` 면 목록에는 남기되 검사에서 뺀다
  (일상 한국어와 겹쳐서 엉뚱하게 걸리는 낱말이다. 이유를 4열에 적는다)

## 그냥 써도 되는 말

여기 있는 것만 설명 없이 쓴다. 없으면 기본값은 「풀어 쓴다」다.

```text
커밋 브랜치 빌드 테스트 로그 태그 푸시 서버 앱 파일 폴더 코드
```

## 설명 없이 써도 되는 약자

여기 없는 대문자 약자는 처음 나올 때 괄호로 한국어 뜻을 붙여야 통과한다.
`RPC` 처럼 새 약자가 새어 나오는 걸 막는 자리다 — 막고 싶은 약자를 늘리는 게 아니라, 허용할 약자만 여기 적는다.
둘째 줄은 계약 조건 번호의 앞자리다 (스킬 · 스크립트 · 에러 · 구조 · 재사용 · 진단 · 안티패턴).

```text
QA AI UI URL HTML CSS JSON YAML XML CSV PNG JPG JPEG SVG PDF GIF MD TXT SH PY JS TS
SK SC ER AR RE DG AP
OK NG PR ID PC OS CPU GPU RAM USB TV KB MB GB TB MS HTTP HTTPS UTF EUC ASCII
```
