### C. auto_route 사용법 문장

저장소 문장:

- [flutter-transition/SKILL.md:22](/Users/jackson/Hub/10_Dev/claude-plugins/.claude/worktrees/after-0928/flutter-toolkit/skills/flutter-transition/SKILL.md:22):  
  “auto_route 11.0 breaking changes — `redirect`가 `redirectUntil`로 리네이밍됐고, `navigateNamed` / `pushNamed` 등 deprecated named navigation 메서드가 제거됐다. `.named` 생성자로 codegen 없이 shorthand named route를 사용할 수 있다. 기존 코드에 `redirect`가 남아 있으면 컴파일 에러 발생”

판정:

- **`redirect` → `redirectUntil` — 맞음.** CHANGELOG는 `AutoRouteGuard.redirect`가 `redirectUntil`로 이름이 바뀌었다고 명시한다. ([CHANGELOG](https://pub.dev/packages/auto_route/changelog), 2026-09-28)
- **deprecated named-navigation API 제거 — 맞음.** 11.0.0은 `navigateNamed`, `popForced`, `replaceNamed`, `pushNamed`, `navigateNamedTo`를 제거하고 `navigatePath`, `pop`, `replacePath`, `pushPath`를 쓰라고 한다.
- **`.named` 생성자를 이용한 codegen 없는 shorthand named route — 맞음.** 단, 이것은 **11.0이 아니라 11.1.0 변경**이다. 원문은 “**add .named constructor to PageRouteInfo and AutoRoute**”라고 한다.
- **기존 `redirect`가 남으면 컴파일 오류 — 가져온 원문에 없음.**  
  추론: 메서드가 rename되어 예전 이름이 제거됐다면 일반적으로 컴파일 오류가 나지만, CHANGELOG가 그 결과를 직접 명시하지는 않는다.
- **`animatePageTransition` 폐기 예정 누락 — 틀림.** 11.1.0 CHANGELOG에 명시된 변경인데 현행 스킬 문장에는 없다.
- **현재 판 번호 누락 — 틀림.** 현재 최신 안정판은 11.2.0이며, 11.2.0에서는 `material_ui`와 `cupertino_ui` 패키지로 이동했다.

## 4. 못 가져온 것 / 열린 질문

- 요청된 네 pub.dev 페이지는 모두 정상적으로 가져왔다. `curl` 재시도는 필요하지 않았다.
- 가져온 원문에서는 다음 두 표현을 직접 확인하지 못했다.

  - `notifyRootObserver: false`가 정확히 “이전 동작을 복원한다”는 설명
  - 남아 있는 `redirect` 호출이 반드시 “컴파일 에러”가 된다는 설명

- 위 두 표현을 유지하려면 pub.dev API 문서나 해당 버전 소스까지 별도로 확인해야 한다. 현재 지정된 패키지 페이지와 CHANGELOG만 근거로 삼는다면 삭제하거나 `추론:`으로 표시하는 것이 안전하다.
