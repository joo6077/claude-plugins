- [phase15-notes.md:130](/Users/jackson/Hub/10_Dev/claude-plugins/.claude/worktrees/after-0928/.harness/.meta/kaizen-0924/phase15-notes.md:130):  
  “Dart 3.7부터 `_`를 여러 번 쓸 수 있어 `(_, _)`로. 린트 `unnecessary_underscores`”
- 현재 예시:
  - [overview.md:155](/Users/jackson/Hub/10_Dev/claude-plugins/.claude/worktrees/after-0928/docs/tone/overview.md:155): `separatorBuilder: (_, __) => divider`
  - [dart-flutter-idioms.md:440](/Users/jackson/Hub/10_Dev/claude-plugins/.claude/worktrees/after-0928/docs/tone/dart-flutter-idioms.md:440): `builder: (_, value, __) => ...`

원문 인용:

- 언어 문서: “**Wildcard variables require a language version of at least 3.7.**”
- 같은 문서: “**Multiple declarations named `_` can exist in the same namespace without a collision error.**”
- 공식 예: `void f(void g(int _, bool _)) {}`
- 린트 페이지: “**AVOID using multiple underscores when a single wildcard will do.**”
- 린트 표시는 “**Released in Dart 3.7**”; 나쁜 예는 `int __`, 좋은 예는 `int _`.

판정:

- **맞음.**
- Dart 언어 버전 3.7 이상에서는 같은 매개변수 목록에 `_`를 여러 번 선언할 수 있다.
- 따라서 두 저장소 예시의 `__`는 각각 `_`로 바꾸는 것이 공식 언어 문서와 권장 린트에 모두 맞는다.
