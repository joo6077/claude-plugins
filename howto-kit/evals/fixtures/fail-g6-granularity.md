# G6 양성 케이스 — 입도 위반

이 파일은 **일부러 G6 를 위반**한다. `확인` 과 `안 보이면` 이 빠졌고 `추정` 비율이 40% 를 넘는다.

- 대상: Android

## S1. Play Console 의 앱 서명 페이지를 연다

- 어디서: `play.google.com/console` > 앱 선택 > 설정 > 앱 서명
- 무엇을: 앱 서명 (메뉴)
- 동작: 열기
- 값: 입력 없음
- 출처: [추정]

## S2. 업로드 키 인증서를 다운로드한다

- 어디서: 앱 서명 페이지
- 무엇을: 업로드 키 인증서 (버튼)
- 동작: 다운로드
- 값: 입력 없음
- 출처: [추정]

## S3. 인증서 지문을 복사한다

- 어디서: 앱 서명 페이지
- 무엇을: SHA-1 인증서 지문 (필드)
- 동작: 선택
- 값: 입력 없음
- 확인: 클립보드에 40자 16진수가 복사된다
- 안 보이면: 권한 — 관리자 계정이 필요하다
- 출처: https://support.google.com/googleplay/android-developer/answer/9842756 (조회 2026-09-08)
