# 픽스처 — 출처 줄 수는 Step 수와 같지만 한 Step 에 둘 · 다른 Step 에 0 (G1 misplaced)

이 파일은 `guide_gate` 의 G1 이 전체 수만 맞추지 않고 Step 마다 출처가 정확히 하나인지 세는지 증명하는 입력이다.
Step 1 에 출처 둘 · Step 2 에 0 이라 전체 수(2 = 2)는 맞지만 FAIL 이어야 한다.

## Step 1: FlutterFire CLI 설치

```bash
dart pub global activate flutterfire_cli
```
