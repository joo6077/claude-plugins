# 픽스처 — 한 Step 에 출처 둘 · 출처 없는 Step 없음 (G1)

이 파일은 `guide_gate` 의 G1 이 출처가 남는 배치를 잡는지 증명하는 입력이다.
Step 1 에 출처 둘 · Step 2 에 하나라 출처 없는 Step 은 없지만, 출처 줄이 Step 수보다 많아 FAIL 이어야 한다.

## Step 1: FlutterFire CLI 설치

```bash
dart pub global activate flutterfire_cli
```

**출처:** <https://firebase.google.com/docs/flutter/setup> (조회 2026-09-08)
