# 프로젝트 오버레이 템플릿

프로젝트별 파라미터를 담는 파일. **프로젝트가 소유** 하며 킷은 값을 정하지 않는다. 감지 규칙은 `project-detection.md` 가 소유한다.

**생성 위치:** 프로젝트의 `.claude/tone-project.md`

## 골격

```text
# tone-kit 프로젝트 파라미터

- 감지 일시: {YYYY-MM-DD}
- 어댑터: {dart-flutter | 없음}
- 주석 언어: {ko | en | ...}

## 결정론적 감지값

| 키 | 값 | 감지 근거 |

| `token_class_names` | {클래스 목록} | {선언 위치} |

```

## 규칙

- 결정론적 감지값은 코드에서 다시 읽으면 되므로 값이 낡아도 복구된다. **확인이 필요한 값은 낡으면 조용히 틀린다** — 확인 날짜를 반드시 남긴다.
- 용어 번역표의 기준 디렉토리는 **정리 이력이 없는 쪽** 으로 정한다. 정리 대상이던 영역을 기준으로 삼으면 오염이 규칙으로 승격된다.
- 이 파일에 규칙 본문을 복사하지 않는다. 값과 판정만 담는다.
- `codegen_cmd` 는 프로젝트 설정에 이미 있으면 그것을 읽는다. 중복 스키마를 만들지 않는다.
