# doc 주석 3변종 (Dart/Flutter)

`///` doc 주석 포맷. 실측 반환값 줄 577건 · 파라미터 줄 788건.

**채우는 주체:** `tone-scaffold` · **어댑터:** dart-flutter · **라벨 소유:** `locale-korean.md`

## 변종 1 — 파라미터 + 반환값

```dart
/// {한 줄 요약. 무엇을 하는가.}
///
/// {선택: 언제 쓰는가 / 부수효과 / 제약. 없으면 이 블록 생략.}
///
/// - [{param}]: {설명}
/// - {label_return}: {반환 조건과 의미}
Future<bool> {methodName}({Type} {param}) async {
```

## 변종 2 — 반환값 없음

```dart
/// {한 줄 요약}
///
/// - [{param}]: {설명}
/// - {label_return}: {label_void}
void {methodName}({Type} {param}) {
```

## 변종 3 — 파라미터 없음

```dart
/// {한 줄 요약}
///
/// - {label_return}: {label_void}
void {methodName}() {
```

## 줄 순서 (고정)

1. 요약 한 줄
2. 빈 `///`
3. 선택 설명 블록 + 빈 `///`
4. `- [param]:` 목록 (선언 순서대로)
5. `- {label_return}:` — **항상 마지막**

## 커버리지 판정

| 대상 | doc |
|---|---|
| 로직·부수효과가 있는 메서드 | 필수 |
| 공개 API 계약 | 필수 |
| `build()` | 불필요 |
| thin wrapper (한 줄 위임) | 불필요 |
| 메서드 본문 내부 람다·클로저 | **금지** |
| 클래스 필드 | 비자명한 계약이 있을 때만. 이름을 한국어로 옮기기만 하는 doc 은 금지 |

## 완료 전 대조 (전부 0이어야 한다)

```text
1. `{label_return}: N/A` 잔존
2. 로직 메서드에 `///` 누락
3. `- [param]:` 만 있고 `- {label_return}:` 없음
4. doc 본문 안에 섹션 헤딩 (`/// 정책:`, `/// 참고:`, `/// 주의:`)
```

## 규칙

- `{label_return}` / `{label_void}` 는 **언어 의존 상수** 다. 표기를 바꾸려면 전수 치환한다. 부분 변경은 금지 — grep 게이트가 깨진다.
- void 메서드에 반환값 줄을 남기는 것은 노이즈가 아니라 관례다 (실측 246건이 이 형태). 프로젝트가 반대로 정했다면 그것도 유효하되 전수 일관해야 한다.
- `[param]` 안의 식별자 철자를 실제 선언과 대조한다. 오타는 링크가 깨져도 컴파일은 통과한다.
- 메서드 이름을 한국어로 옮기기만 한 요약은 지운다 — 요약은 "무엇을" 이 아니라 "왜/언제" 를 담을 때 값이 생긴다.
