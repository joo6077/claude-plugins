4px/8px 베이스 그리드, 스페이싱 토큰, 네거티브 스페이스, 콘텐츠 밀도, 터치 타겟 -- 간격과 레이아웃의 모든 것을 인터랙티브하게 탐색합니다.

Principles
4가지 간격 원칙

NNGroup, Material Design, 게슈탈트 심리학에서 도출한 핵심 원칙입니다.

일관된 간격 체계

모든 간격 값은 기본 단위의 배수로 제한한다. 13px vs 15px를 고민할 필요 없이 8px 또는 16px 중 선택. 선택지를 제한해야 계층 구조와 인터랙션에 집중 가능.

여백은 디자인 도구

여백은 "비어있는 공간"이 아니라 정보 계층을 구성하는 능동적 도구. NNGroup 연구에서 마이크로/매크로 여백이 모두 부족하면 1.5배 더 많은 시간을 써서 정보를 찾음.

내부 간격 ≤ 외부 간격

관련 요소 간 내부 간격(padding)은 비관련 요소 간 외부 간격(margin)보다 작아야 한다. 게슈탈트 근접성 원칙: 가까이 있는 요소는 관련된 것으로 인식.

그리드 기반 정렬

그리드는 사용자의 스캔 용이성을 향상시킨다. 정렬이 무너진 UI는 "대충 만든" 인상 -- 브랜드 신뢰도에 직접 영향.

Grid
4px / 8px 베이스 그리드

4px 단위는 미세 조정, 8px 단위는 대부분의 레이아웃에 사용. 오버레이 토글로 그리드를 확인하세요.

Whitespace
네거티브 스페이스 데모

동일한 콘텐츠에 서로 다른 여백을 적용하면 "답답함"과 "여유"가 극명하게 달라진다. 마이크로 + 매크로 여백이 모두 필요.

마이크로 여백 부족 (6px)
콘텐츠가 경계에 너무 가깝다. 텍스트가 답답하게 느껴지고, 정보 계층이 모호해진다. 사용자는 읽기를 포기할 수 있다.

기본 여백 (16px)
적절한 패딩으로 콘텐츠가 숨 쉴 공간을 확보한다. 텍스트 가독성이 향상되고 카드 구조가 명확해진다.

여유 여백 (32px)
넉넉한 여백은 프리미엄 느낌을 준다. 고급 브랜드나 에디토리얼 레이아웃에 적합하다. 정보 밀도가 낮아진다.

WCAG 2.5.8 예외 조건 5가지

1. 간격(Spacing): 24px 원이 인접 타겟과 겹치지 않으면 통과

2. 동등 대안: 같은 페이지에 기준 충족하는 동일 기능 컨트롤이 있는 경우

3. 인라인: 문장 내부에 있거나 line-height로 크기가 제한되는 경우

4. 사용자 에이전트: 브라우저 기본 렌더링 컨트롤 (날짜 선택기 등)

5. 필수적: 타겟 위치가 정보에 본질적인 경우 (지도 핀 등)
