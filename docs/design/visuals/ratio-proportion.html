✧ Design Foundations v0.3.0

비율과 프로포션

임의 수치 대신 체계적 비율을 적용하면 시각적 조화, 일관성, 확장성을 동시에 얻는다. 수학적 관계 기반 크기와 간격은 인간 시각 체계가 자연스럽게 인지한다.

시각적 조화수학적 관계 기반 크기/간격은 인간 시각 체계가 자연스럽게 인지한다
일관성하나의 비율 체계에서 파생된 값들이 디자인 시스템 전체에 통일감을 부여한다
확장성비율 기반 레이아웃은 다양한 화면 크기에서 비례를 유지한다
의사결정 효율"왜 이 크기인가?"에 대한 답이 명확해져 리뷰와 협업이 빨라진다
01

황금비 (Golden Ratio, 1:1.618)

황금비(φ, phi)는 약 1:1.618의 비율로, 자연계와 예술에서 반복 등장하는 수학적 상수다. UI 디자인에서는 레이아웃 분할, 타이포그래피 스케일, 간격 체계에 활용된다.

02

3분할 법칙 (Rule of Thirds)

화면을 가로 3등분, 세로 3등분하여 9개 영역으로 나눈다. 교차점(power point) 4곳에 핵심 요소를 배치하면 시각적 긴장감과 균형을 동시에 얻는다.

화면 비율 체계

디바이스별 화면 비율이 다르므로 고정 비율 레이아웃은 주의가 필요하다. 주요 비율과 용도를 시각적으로 비교한다.

04

모듈러 스케일 (Modular Scale)

기준값(base)에 일정한 비율(ratio)을 반복적으로 곱하여 생성하는 수열이다. 공식: value = base × ratio^n — Tim Brown이 A List Apart에서 소개한 개념.

🖩 모듈러 스케일 계산기
기준값과 비율을 입력하면 전체 스케일이 자동으로 생성됩니다
📊 스케일 비율 비교 테이블
Minor Second부터 Golden Ratio까지 — 각 비율의 특성과 적합한 용도
비율이름값특성적합한 용도
Minor Second1.067매우 미세한 차이밀집 데이터 UI
Major Second1.125미세한 차이대시보드, 테이블
Minor Third1.200부드러운 대비모바일 UI
Major Third1.250적당한 대비일반 웹 UI
Perfect Fourth1.333명확한 계층가장 보편적인 웹 UI
Augmented Fourth1.414극적인 대비프로모션, A4 비율
Perfect Fifth1.500강한 대비에디토리얼
Golden Ratio1.618극적 대비고급 브랜드, 에디토리얼
🔀 이중 기준 스케일 (Double-Stranded Scale)
두 개의 기준값을 사용하여 더 촘촘한 스케일을 생성하는 기법 (Tim Brown)
// 기준 A: 18px × 1.618^n A: 18, 29, 47, 76, 123, 199... // 기준 B: 190px ÷ 1.618^n B: 190, 117, 73, 45, 28, 17... // 병합 스케일 → 17, 18, 28, 29, 45, 47, 73, 76, 117, 123, 190, 199...
↔️ 간격(Spacing)에의 적용
타이포그래피뿐 아니라 간격 시스템에도 동일한 비율을 적용한다
:root { --space-base: 16px; --space-ratio: 1.333; --space-3xs: 7px; /* base ÷ ratio³ */ --space-2xs: 9px; /* base ÷ ratio² */ --space-xs: 12px; /* base ÷ ratio */ --space-sm: 16px; /* base (기준) */ --space-md: 21px; /* base × ratio */ --space-lg: 28px; /* base × ratio² */ --space-xl: 38px; /* base × ratio³ */ }

06

CSS aspect-ratio 데모

모던 CSS에서 비율 컨테이너를 직접 선언할 수 있다 (Chrome 88+, Firefox 89+, Safari 15.4+). 코드를 수정하면 실시간으로 프리뷰가 반영됩니다.

📝 코드
/* 16:9 비디오 컨테이너 */ .video-container { aspect-ratio: 16 / 9; width: 100%; }

16 : 9

07

안티패턴

비율 체계를 무시하거나 잘못 적용할 때 발생하는 일반적인 문제와 해결책.

✘ 임의의 비율

매직 넘버 크기

13px, 17px, 23px 같은 임의의 수치를 사용하면 시스템 내 일관성이 무너지고, "왜 이 크기인가?"에 대답할 수 없다.

✔ 체계적 비율

모듈러 스케일 적용

base: 16px, ratio: 1.333에서 파생된 12px, 16px, 21px, 28px을 사용하면 모든 크기가 수학적으로 연결된다.

✘ 일관성 없는 비율

혼합 비율 시스템

한 페이지에서 황금비와 Perfect Fifth를 동시에 사용하거나, 카드마다 다른 이미지 비율을 적용하면 시각적 통일감이 깨진다.

✔ 단일 비율 체계

하나의 비율로 통일

프로젝트 전체에 하나의 비율(예: Perfect Fourth 1.333)을 기본으로 채택하고, 필요시 의도적으로 벗어난다.

✘ 맹목적 적용

수학의 절대화

황금비를 모든 뷰포트에 강제하거나, 8px 그리드와 충돌하는 스케일 값을 고집하면 오히려 비효율적이다.

✔ 실용적 판단

도구로서의 비율

스케일에서 벗어난 값이 시각적으로 더 적합하면 그 값을 쓴다. 8의 배수로 라운딩하는 것이 실용적이다.
