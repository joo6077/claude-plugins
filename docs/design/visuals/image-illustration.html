이미지 & 일러스트 사용 원칙

UI에서 이미지와 일러스트를 선택, 배치, 최적화, 접근성 처리하는 원칙을 시각적으로 정리한다.

Principles

핵심 원칙

이미지는 콘텐츠를 보조하지 대체하지 않는다. 목적, 일관성, 성능 네 가지 축으로 이미지를 판단한다.

이미지는 콘텐츠를 보조한다

이미지가 없으면 이해할 수 없는 UI는 접근성에 실패한 UI다. 대부분의 이미지는 텍스트를 시각적으로 보강하는 역할이다.

모든 이미지는 목적이 있어야 한다

"이 이미지를 제거하면 무엇이 달라지는가?"에 답할 수 없다면 불필요한 이미지다. 페이지 로딩 시간만 늘리고 주의를 분산시킨다.

일관된 시각 언어를 유지한다

사진, 3D, 2D 일러스트, 아이콘을 무작위 혼용하면 브랜드 정체성이 훼손된다. 하나의 스타일을 선택하고 일관되게 적용한다.

성능은 시각적 품질만큼 중요하다

고해상도 3초 로딩보다 최적화된 0.5초 로딩이 UX에 유리하다. LCP(Largest Contentful Paint)는 2.5초 이내가 "Good"이다.

Decision Tree

사진 vs 일러스트 의사결정 트리

질문에 답하며 현재 상황에 사진이 적합한지, 일러스트가 적합한지 판단한다. 각 단계를 클릭하여 진행한다.

Crop & Aspect Ratio

이미지 크롭 비교

동일한 피사체를 다양한 비율로 크롭하면 전달하는 느낌이 달라진다. 용도별 권장 비율과 해상도를 확인한다.

Focal Point

초점(Focal Point) 시각화

삼분법(Rule of Thirds) 교차점에 핵심 피사체를 배치하면 시각적 균형이 잡힌다. Safe Zone(중앙 60%)에 초점을 두면 다양한 비율 크롭에서도 피사체가 유지된다.

삼분법(Rule of Thirds)

가로/세로를 3등분하는 선의 교차점에 핵심 피사체를 배치한다. 4개의 교차점 중 가장 밝은 점이 주요 초점이다.

SAFE ZONE (60%)

Safe Zone 크롭 영역

양쪽 20%는 반응형 크롭 시 잘릴 수 있다. 핵심 피사체는 중앙 60% 영역에 위치시킨다.

Lazy Loading

Lazy Loading 타임라인

페이지 로딩 시 이미지가 언제, 어떻게 로드되는지 시간순으로 시각화한다. LCP 이미지에는 절대 lazy를 적용하지 않는다.

히어로 이미지 즉시 로드 (eager)
LCP 이미지는 loading="eager"와 fetchpriority="high"로 최우선 로드. Above the fold에 위치.
<img src="hero.webp" loading="eager" fetchpriority="high" alt="...">
첫 화면 이미지 로드
뷰포트 안에 보이는 모든 이미지가 기본 우선순위로 로드된다. width/height 속성으로 Layout Shift를 방지한다.
뷰포트 접근 감지
사용자가 스크롤하면 브라우저가 뷰포트에 접근하는 이미지를 감지한다. loading="lazy" 이미지의 로드가 시작된다.
Below the fold 이미지 Lazy Load
스크롤 아래 이미지에만 lazy 적용. 초기 로딩 시간을 줄이고 대역폭을 절약한다.
<img src="photo.webp" loading="lazy" alt="..." width="800" height="600">
이미지 디코딩 및 렌더링 완료
플레이스홀더(LQIP, BlurHash, 스켈레톤)가 실제 이미지로 교체된다. 전환 애니메이션으로 부드럽게 표시.
LCP 이미지에 lazy 적용 금지
LCP 이미지에 loading="lazy"를 적용하면 오히려 LCP가 악화된다. Above the fold 이미지는 반드시 loading="eager"(기본값)을 유지한다.

Placeholders

플레이스홀더 전략 데모

이미지 로딩 중 빈 공간이나 깜빡임을 방지하는 기법. 상황에 따라 적합한 전략이 다르다.

blur-up 효과

LQIP (Blur-up)

극소 해상도(20-40px) 이미지를 블러 처리. 사진 중심 레이아웃에 적합.

BlurHash

BlurHash

4x3 해시 문자열로 블러 이미지 생성. 모바일 앱에서 최소 데이터로 표현.

주요 색상 추출

단색 배경

이미지 주요 색상 추출 후 배경 사용. 갤러리, 카드에 적합.

스켈레톤 Shimmer

이미지 영역에 shimmer 애니메이션. 피드, 리스트에 적합.

width x height

고정 영역 (w/h)

이미지 크기 미리 지정으로 Layout Shift 방지. 모든 이미지에 필수.

Anti-Patterns

스톡 사진 안티패턴 갤러리

모든 B2B/SaaS 사이트에서 반복적으로 등장하는 스톡 사진 클리셰. 차별화 불가능한 이미지를 실제 콘텐츠로 대체한다.
