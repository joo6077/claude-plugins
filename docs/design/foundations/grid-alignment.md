# 그리드 & 정렬

UI 레이아웃의 뼈대가 되는 그리드 시스템, 베이스라인 정렬, 반응형 전략, 시각적 균형을 정리한다.

---

## 원칙

### 1. 정렬은 질서를 만들고, 질서는 인지 부하를 줄인다

정렬되지 않은 요소는 뇌가 각 요소의 위치를 개별적으로 처리해야 하므로 인지 비용이 증가한다. 그리드에 정렬된 레이아웃은 사용자가 "어디를 봐야 하는지" 예측할 수 있게 만든다. NNGroup은 미학적으로 우수한 디자인의 공통점으로 **그리드 정렬**을 꼽았다.

> **출처:** [NNGroup — Why Does a Design Look Good?](https://www.nngroup.com/articles/why-does-design-look-good/)

### 2. 그리드는 제약이 아니라 프레임워크다

그리드는 모든 요소를 격자에 가두라는 뜻이 아니다. 일관된 기준선을 제공하여 "어디에 배치할지"에 대한 의사결정 비용을 줄이는 것이다. 의도적으로 그리드를 벗어나는 요소는 오히려 시각적 강조 효과를 낸다.

> **출처:** [NNGroup — Using Grids in Interface Designs](https://www.nngroup.com/articles/using-grids-in-interface-designs/)

### 3. 일관된 거터와 마진이 컬럼 수보다 중요하다

Material Design의 반응형 그리드는 컬럼 너비보다 마진과 거터의 일관성에 초점을 맞춘다. 컬럼 너비는 화면 크기에 따라 유동적으로 변하지만, 거터와 마진은 브레이크포인트 범위 내에서 고정값을 유지한다.

> **출처:** [Material Design 2 — Responsive Layout Grid](https://m2.material.io/design/layout/responsive-layout-grid.html)

### 4. 광학 정렬이 수학적 정렬보다 우선한다

삼각형 아이콘의 재생 버튼을 정확히 중앙에 배치하면 왼쪽으로 치우쳐 보인다. 시각적 무게 중심이 기하학적 중심과 다르기 때문이다. 최종 판단은 눈으로 해야 한다.

> **출처:** [Figma — Gestalt Principles](https://www.figma.com/resource-library/gestalt-principles/)

## 컬럼 그리드 시스템

### 그리드의 3요소

모든 컬럼 그리드는 세 가지 요소로 구성된다.

| 요소 | 역할 | 설명 |
|------|------|------|
| **Column (컬럼)** | 콘텐츠 영역 | 콘텐츠가 배치되는 세로 영역. 너비는 퍼센트로 정의 |
| **Gutter (거터)** | 컬럼 간 간격 | 컬럼 사이의 고정 폭 여백. 콘텐츠 간 호흡 공간 |
| **Margin (마진)** | 화면 가장자리 여백 | 콘텐츠 영역과 화면 가장자리 사이의 공간 |

### 12컬럼 그리드

가장 널리 사용되는 컬럼 수다. 12는 1, 2, 3, 4, 6으로 나눌 수 있어 다양한 레이아웃 조합이 가능하다.

```
|M| C  |G| C  |G| C  |G| C  |G| C  |G| C  |G| C  |G| C  |G| C  |G| C  |G| C  |G| C  |M|
   1col     2col     3col     4col     5col     6col     7col     8col     9col    10col   11col   12col
```

일반적인 레이아웃 분할:

| 레이아웃 | 컬럼 배분 | 용도 |
|----------|-----------|------|
| 1단 중앙 | 8/12 (좌우 2컬럼 여백) | 블로그 본문, 기사 |
| 2단 균등 | 6/12 + 6/12 | 비교 레이아웃, 대시보드 |
| 2단 비대칭 | 8/12 + 4/12 | 메인 콘텐츠 + 사이드바 |
| 3단 균등 | 4/12 + 4/12 + 4/12 | 카드 그리드, 기능 소개 |
| 4단 균등 | 3/12 x 4 | 제품 목록, 갤러리 |

### 8컬럼 그리드

태블릿에서 주로 사용한다. Material Design은 600dp 이상에서 8컬럼을 권장한다. 12컬럼보다 단순하지만 2단, 4단 레이아웃을 충분히 지원한다.

### 4컬럼 그리드

모바일 전용. Material Design은 360dp 이하에서 4컬럼을 권장한다. 대부분의 모바일 레이아웃은 1–2단이므로 4컬럼으로 충분하다.

### 컬럼/거터/마진 수치 (Material Design 기준)

| 브레이크포인트 | 컬럼 수 | 거터 | 마진 |
|---------------|---------|------|------|
| 0–599dp (모바일) | 4 | 16dp | 16dp |
| 600–904dp (태블릿) | 8 | 16dp | 24dp |
| 905–1239dp (소형 데스크톱) | 12 | 24dp | 24dp |
| 1240–1439dp (중형 데스크톱) | 12 | 24dp | 200dp (고정) |
| 1440dp+ (대형 데스크톱) | 12 | 24dp | auto (중앙 정렬) |

> **출처:** [Material Design 2 — Responsive Layout Grid](https://m2.material.io/design/layout/responsive-layout-grid.html)

## 베이스라인 그리드

### 4px / 8px 베이스라인

베이스라인 그리드는 수평 방향의 정렬 기준선이다. 모든 요소의 높이, 패딩, 마진을 4px 또는 8px의 배수로 설정하면 수직 리듬이 일관되게 유지된다.

| 단위 | 용도 | 예시 값 |
|------|------|---------|
| **4px** (하프 그리드) | 미세 조정 | 아이콘 내부 여백, 텍스트-아이콘 간격 |
| **8px** (풀 그리드) | 기본 간격 단위 | 패딩, 마진, 컴포넌트 높이 |
| **16px** | 중간 간격 | 카드 내부 패딩, 섹션 간격 |
| **24px** | 넓은 간격 | 그룹 간 간격, 거터 |
| **32px** | 섹션 간격 | 콘텐츠 블록 구분 |
| **48px** | 대형 간격 | 페이지 영역 구분 |

### 텍스트와 베이스라인 정렬

폰트 사이즈는 8의 배수가 아니어도 괜찮다. 중요한 것은 **행간(line-height)**이 베이스라인 그리드에 맞는 것이다.

```
[GOOD] font-size: 15px, line-height: 24px (8의 배수)
[GOOD] font-size: 14px, line-height: 20px (4의 배수)
[BAD]  font-size: 16px, line-height: 22px (그리드에 안 맞음)
[BAD]  font-size: 14px, line-height: 1.5 (21px → 그리드 어긋남)
```

### Hard Grid vs Soft Grid

| 방식 | 설명 | 장단점 |
|------|------|--------|
| **Hard Grid** | 모든 요소를 4px/8px 격자에 정확히 배치 | 인쇄 디자인에 적합, 디지털에서는 비효율적 |
| **Soft Grid** | 요소 간 간격만 4px/8px 배수로 유지 | 실용적, 현대 UI/UX의 표준 접근법 |

현대 디지털 제품에서는 Soft Grid가 표준이다. 모든 픽셀을 격자에 맞추려 하면 생산성이 크게 떨어진다.

> **출처:** [Spec.fm — The 8pt Grid](https://spec.fm/specifics/8-pt-grid)

## 정렬 규칙

### 좌측 정렬 (Left Alignment)

기본 정렬 방식이다. 왼쪽 가장자리가 일관된 시선 앵커 역할을 하므로 긴 텍스트, 폼 라벨, 리스트에 가장 적합하다. 서구권 및 한국어 UI에서 좌측 정렬이 기본이다.

적합한 상황:
- 본문 텍스트 (3줄 이상)
- 폼 라벨 + 입력 필드
- 리스트 아이템
- 테이블 텍스트 컬럼

### 중앙 정렬 (Center Alignment)

짧은 텍스트에만 사용한다. 줄 수가 늘어나면 왼쪽 가장자리가 들쭉날쭉해져 읽기 어려워진다.

적합한 상황:
- 히어로 타이틀 (1–2줄)
- 다이얼로그 제목/메시지
- 빈 상태(Empty State) 안내
- 탭 라벨, 내비게이션 아이템

### 우측 정렬 (Right Alignment)

숫자를 다룰 때 사용한다. 소수점이나 자릿수가 맞아야 하는 데이터에서 우측 정렬이 비교를 용이하게 만든다.

적합한 상황:
- 테이블의 숫자 컬럼 (금액, 수량, 비율)
- 타임스탬프 (리스트 아이템 우측)
- 가격 표시

### 광학 정렬 vs 수학적 정렬

수학적 중앙이 시각적 중앙과 다른 경우가 빈번하다.

| 상황 | 수학적 정렬 문제 | 광학 보정 |
|------|-----------------|-----------|
| 삼각형 재생 아이콘 | 무게 중심이 왼쪽에 치우침 | 2–3px 오른쪽으로 이동 |
| 원형 아바타 + 텍스트 | 원이 사각형보다 작아 보임 | 아바타를 텍스트보다 2px 위로 |
| 텍스트 버튼 | 글자 하단 디센더로 인해 위로 치우쳐 보임 | padding-bottom을 1–2px 더 줌 |
| 아이콘 + 텍스트 | 아이콘이 텍스트 중앙보다 높아 보임 | 아이콘을 1px 아래로 조정 |

## 반응형 그리드

### 브레이크포인트 전략

| 명칭 | 범위 | 컬럼 | 대표 디바이스 |
|------|------|------|---------------|
| **xs** | 0–599px | 4 | 스마트폰 |
| **sm** | 600–904px | 8 | 소형 태블릿 |
| **md** | 905–1239px | 12 | 태블릿, 소형 데스크톱 |
| **lg** | 1240–1439px | 12 | 데스크톱 |
| **xl** | 1440px+ | 12 | 대형 데스크톱 |

### 유동(Fluid) 그리드 vs 고정(Fixed) 그리드

| 방식 | 동작 | 장점 | 단점 |
|------|------|------|------|
| **Fluid** | 컬럼이 화면 너비에 따라 늘어남 | 모든 화면 크기에 최적화 | 극단적 해상도에서 콘텐츠 변형 |
| **Fixed** | 컬럼이 고정 너비, 마진만 유동 | 레이아웃 예측 가능 | 중간 크기에서 빈 공간 발생 |
| **Hybrid** | 특정 범위까지 Fluid, 이후 max-width 고정 | 실무에서 가장 선호 | 구현 복잡도 약간 증가 |

### 그리드 축소(Collapse) 전략

화면이 작아질 때 레이아웃을 재배치하는 패턴이다.

| 패턴 | 설명 | 예시 |
|------|------|------|
| **Stack** | 수평 → 수직 전환 | 3컬럼 카드 → 1컬럼 스택 |
| **Drop** | 마지막 컬럼 탈락 | 사이드바 제거, 메인만 표시 |
| **Reflow** | 컬럼 수 변경 | 4컬럼 → 2컬럼 → 1컬럼 |
| **Squeeze** | 컬럼 내부 콘텐츠 축소 | 여백 줄이기, 이미지 축소 |
| **Off-canvas** | 화면 밖으로 이동 | 사이드 내비게이션 드로어 |

### Flutter 반응형 구현

```dart
// LayoutBuilder로 브레이크포인트 분기
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth >= 1240) return _desktopLayout();
    if (constraints.maxWidth >= 600)  return _tabletLayout();
    return _mobileLayout();
  },
)
```

## 시각적 무게 균형

### 시각적 무게에 영향을 주는 요소

| 요소 | 무거운 쪽 | 가벼운 쪽 |
|------|-----------|-----------|
| 크기 | 큰 요소 | 작은 요소 |
| 색상 | 어두운 색, 높은 채도 | 밝은 색, 낮은 채도 |
| 밀도 | 텍스트/요소가 빽빽함 | 여백이 넓음 |
| 위치 | 화면 상단 | 화면 하단 |
| 형태 | 불규칙한 모양 | 규칙적/기하학적 모양 |
| 텍스처 | 복잡한 이미지 | 단색 |

### 대칭 균형 vs 비대칭 균형

**대칭 균형**: 중심축 기준으로 좌우가 거울처럼 대칭. 안정적이고 공식적인 느낌. 설정 화면, 로그인 페이지에 적합.

**비대칭 균형**: 좌우가 다르지만 시각적 무게는 동일. 역동적이고 현대적인 느낌. 뉴스 피드, 대시보드에 적합. 큰 이미지(무거운) 반대편에 작은 텍스트 + 넓은 여백(가벼운)을 배치하면 균형이 맞는다.

### 균형 검증 방법

1. **중심선 테스트**: 화면 중앙에 세로선을 긋고 좌우의 시각적 무게를 비교
2. **회전 테스트**: 디자인을 180도 회전 — 균형이 무너지면 한쪽에 무게가 치우친 것
3. **축소 테스트**: 10% 크기로 축소하여 전체 밀도 분포를 확인

## 안티패턴

| 안티패턴 | 문제 | 해결 |
|----------|------|------|
| 매직 넘버 간격 | 13px, 17px, 23px 같은 임의의 값 | 4/8px 배수로 통일 |
| 정렬 기준 불일치 | 좌측 정렬과 중앙 정렬이 섞인 폼 | 하나의 정렬 기준 선택 후 일관 적용 |
| 거터 없는 컬럼 | 콘텐츠가 붙어 있어 구분 불가 | 최소 16dp 거터 확보 |
| 마진 없는 전체폭 | 콘텐츠가 화면 가장자리에 붙음 | 모바일 최소 16dp, 데스크톱 24dp+ 마진 |
| 반응형 미고려 | 고정 px 레이아웃 | 퍼센트 기반 컬럼 + 브레이크포인트 |
