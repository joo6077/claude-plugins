그리드 & 정렬

UI 레이아웃의 뼈대가 되는 그리드 시스템, 베이스라인 정렬, 반응형 전략, 시각적 균형. 정렬은 질서를 만들고, 질서는 인지 부하를 줄인다.

질서 = 낮은 인지 부하그리드에 정렬된 레이아웃은 사용자가 "어디를 봐야 하는지" 예측 가능하게 만든다
프레임워크, 제약 아님일관된 기준선을 제공하여 의사결정 비용을 줄인다. 의도적 이탈은 강조 효과
거터 > 컬럼 수Material Design은 컬럼 너비보다 마진과 거터의 일관성에 초점을 맞춘다
광학 우선시각적 무게 중심이 기하학적 중심과 다르다. 최종 판단은 눈으로 해야 한다

03

베이스라인 그리드

수평 방향의 정렬 기준선. 모든 요소의 높이, 패딩, 마진을 4px 또는 8px의 배수로 설정하면 수직 리듬이 일관된다.

─ 베이스라인 오버레이

섹션 제목 (24px / line-height: 32px)

본문 텍스트는 15px 크기에 line-height 24px을 사용합니다. 8px 그리드의 배수인 24px 행간으로 수직 리듬이 유지됩니다. 모든 간격은 8의 배수입니다.

캡션 텍스트 (13px / line-height: 20px) — 4px 배수로 보조 그리드에 맞춤

GOOD
font-size: 15px, line-height: 24px (8의 배수) font-size: 14px, line-height: 20px (4의 배수)
BAD
font-size: 16px, line-height: 22px (그리드에 안 맞음) font-size: 14px, line-height: 1.5 (21px → 그리드 어긋남)
Hard Grid vs Soft Grid
Hard Grid
모든 요소를 4px/8px 격자에 정확히 배치. 인쇄 디자인에 적합, 디지털에서는 비효율적.
Soft Grid (표준)
요소 간 간격만 4px/8px 배수로 유지. 실용적, 현대 UI/UX의 표준 접근법.
간격 단위 체계
단위용도예시 값
4px (하프)미세 조정아이콘 내부 여백, 텍스트-아이콘 간격
8px (풀)기본 간격패딩, 마진, 컴포넌트 높이
16px중간 간격카드 내부 패딩, 섹션 간격
24px넓은 간격그룹 간 간격, 거터
32px섹션 간격콘텐츠 블록 구분
48px대형 간격페이지 영역 구분
04

정렬 규칙

좌측, 중앙, 우측 정렬의 적합한 사용 상황과 가독성 차이를 비교합니다.

↔️ 정렬 방식 비교

⮜ 좌측 정렬 (기본)

왼쪽 가장자리가 일관된 시선 앵커 역할을 한다. 긴 텍스트, 폼 라벨, 리스트에 가장 적합하다. 서구권 및 한국어 UI에서 기본.

적합: 본문(3줄+), 폼 라벨, 리스트, 테이블 텍스트

◆ 중앙 정렬

짧은 텍스트에만 사용. 줄 수가 늘어나면 왼쪽 가장자리가 들쭉날쭉해져 읽기 어렵다.

적합: 히어로 타이틀(1-2줄), 다이얼로그, 탭 라벨

우측 정렬 ⮞

숫자를 다룰 때 사용. 소수점이나 자릿수 비교가 용이.

적합: 금액, 수량, 비율, 타임스탬프

═ 양쪽 정렬 (Justified)

블록 형태로 정돈된 느낌. 단어 간 불규칙한 간격(river)이 발생하여 가독성이 떨어질 수 있다.

주의: 좁은 컬럼에서 "river" 현상 발생. 가급적 사용 자제

광학 정렬 vs 수학적 정렬

수학적 중앙이 시각적 중앙과 다른 경우가 빈번하다. 삼각형 재생 아이콘을 정확히 중앙에 배치하면 왼쪽으로 치우쳐 보인다.

안티패턴

그리드와 정렬에서 흔히 발생하는 실수와 해결책.

✘ 매직 넘버 간격

13px, 17px, 23px

임의의 값은 시스템 일관성을 파괴한다.

✔ 4/8px 배수

8, 16, 24, 32px

체계적인 간격 시스템으로 통일.

✘ 정렬 기준 불일치

좌측+중앙 혼합

하나의 폼에 좌측 정렬과 중앙 정렬이 섞임.

✔ 단일 정렬 기준

일관된 기준 적용

하나의 정렬 기준을 선택 후 일관 적용.

✘ 거터 없는 컬럼

콘텐츠가 붙어 있음

컬럼 간 구분이 불가능.

✔ 최소 16dp 거터

호흡 공간 확보

콘텐츠 간 명확한 시각적 분리.

✘ 마진 없는 전체폭

가장자리에 붙음

콘텐츠가 화면 가장자리에 밀착.

✔ 적절한 마진

모바일 16dp+, 데스크톱 24dp+
