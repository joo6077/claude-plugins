design-concept → design-system → design-mockup → design-component
TEMPLATE
산출물 템플릿
catalog.md — 역할, Variants, 상태, 사이즈, 토큰 매핑, 사용 가이드라인을 포함한 컴포넌트 정의서
역할

컴포넌트의 목적과 사용 맥락을 정의한다. 어떤 상황에서 이 컴포넌트를 사용하는지 명확히 한다.

Variants

primary, secondary, ghost 등 시각적 변형을 나열한다. 각 변형의 용도와 차이를 설명한다.

상태

default, hover, active, disabled, loading, focused 등 인터랙션 상태별 스타일을 정의한다.

사이즈

sm, md, lg 각 사이즈의 높이, 패딩, 폰트 크기를 구체적 수치로 정의한다.

토큰 매핑

디자인 토큰과의 연결을 명시한다. 하드코딩 값 대신 토큰을 참조하여 일관성을 유지한다.

사용 가이드라인

DO/DON'T 규칙을 정의한다. 올바른 사용과 잘못된 사용 예시를 함께 제시한다.
