아이코노그래피

아이콘 크기 체계, 스타일 일관성, 인식률 테스트, 커스텀 아이콘 제작, 아이콘 애니메이션 원칙을 다룬다. 아이콘은 최소한의 시각 요소로 의미를 즉각적으로 전달해야 한다.

크기 체계

아이콘 크기 스케일 (20/24/40/48dp)

Material Design 시스템 아이콘의 기본 크기는 24dp이며, 터치 타겟은 48dp이다. 광학 크기 축으로 크기별 획 두께를 자동 최적화한다.

스타일 일관성

Outlined vs Filled 비교

같은 화면 내에서 Outlined와 Filled는 상태 표현 용도로만 혼용한다. 선택된 탭은 Filled, 비선택 탭은 Outlined로 표시한다.

Outlined (fill: 0) -- 비선택, 기본 UI
Filled (fill: 1) -- 선택/활성 상태
바텀 내비게이션 예시 (선택 탭 = Filled)
굵기 매칭

텍스트 Weight ↔ 아이콘 Weight

접근성

아이콘 접근성 어노테이션

의미를 전달하는 아이콘에는 aria-label을, 장식적 아이콘에는 aria-hidden="true"를 제공한다.

의미 전달 아이콘 (aria-label)
<!-- 검색 버튼 --> <button aria-label="검색"> <svg aria-hidden="true">... </button> <!-- 독립 아이콘 --> <svg role="img" aria-label="경고: 저장 공간 부족"> ... </svg>
장식적 아이콘 (aria-hidden)
<!-- 텍스트 옆 장식 아이콘 --> <span> <svg aria-hidden="true">... 설정 </span> <!-- 카테고리 라벨 아이콘 --> <li> <svg aria-hidden="true"/> <span>음악</span> </li>
올바른 SVG 아이콘 구조
<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" <!-- CSS color로 제어 --> stroke-width="2" stroke-linecap="round" stroke-linejoin="round"> <path d="M12 5v14M5 12h14"/> </svg>

  • 선택/비선택 상태만 fill 축으로 구분하는가?
  • 아이콘 weight가 인접 텍스트 폰트 무게와 시각적으로 매칭되는가?
  • 광학 크기(opsz)가 표시 크기에 맞게 설정되어 있는가?
  • 인터랙티브 아이콘의 터치 타겟이 플랫폼 최소 기준을 충족하는가?
  • 의미를 전달하는 아이콘에 aria-label이 제공되는가?
