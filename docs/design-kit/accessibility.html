Accessibility

접근성

WCAG 2.2 핵심 원칙(POUR), 색상 대비, 터치 타겟 크기, 스크린 리더, 키보드 네비게이션, 인지 접근성, 모션 감수성까지 -- 모든 사용자를 위한 디자인을 인터랙티브하게 탐색합니다.

Principles
POUR 원칙

WCAG 2.2의 4가지 근본 원칙. 모든 접근성 성공 기준은 이 원칙 중 하나에 속한다.

👁
Perceivable
인식 가능
  • 대체 텍스트 제공 (SC 1.1.1)
  • 자막 및 음성 해설 (SC 1.2.x)
  • 다양한 표현 방식 (SC 1.3.x)
  • 전경/배경 구분 (SC 1.4.x)
🦭
Operable
운용 가능
  • 키보드 접근 (SC 2.1.x)
  • 충분한 시간 제공 (SC 2.2.x)
  • 발작 유발 회피 (SC 2.3.x)
  • 탐색 방법 제공 (SC 2.4.x)
💡
Understandable
이해 가능
  • 텍스트 가독성 (SC 3.1.x)
  • 예측 가능한 동작 (SC 3.2.x)
  • 오류 방지/수정 (SC 3.3.x)
  • 일관된 탐색 구조
🔧
Robust
견고성
  • 마크업 호환성 (SC 4.1.x)
  • 이름/역할/값 확인 (SC 4.1.2)
  • 상태 메시지 감지 (SC 4.1.3)
  • 보조 기술 안정적 해석

실무 권장사항
  • 디자인 단계에서 대비 검증 도구를 쓴다 (WebAIM Contrast Checker, Stark 등)
  • 브랜드 컬러가 기준을 충족하지 않으면 대체 팔레트를 준비한다

  • 색상만으로 정보를 전달하지 않는다 — 패턴 · 아이콘 · 텍스트 레이블을 병행한다
Touch Targets
터치 타겟 크기

Cognitive Accessibility
인지 접근성

인지 장애(학습 장애, ADHD, 자폐 스펙트럼, 노인성 인지 저하)는 전체 장애의 약 40%를 차지합니다.

📝
단순한 언어
전문 용어, 약어, 이중 부정을 피한다. "유효하지 않은 입력" → "이메일에 @ 기호가 필요합니다"
🔍
예측 가능한 UI
같은 기능은 항상 같은 위치, 같은 모양. 뒤로가기는 좌측 상단, 저장은 우측 하단.
🚫
주의 분산 최소화
자동 재생 미디어, 깜빡이는 배너, 움직이는 광고를 제거한다.
⏰
충분한 시간
세션 타임아웃 전 경고 + 연장 옵션. "세션이 5분 후 만료됩니다 [연장하기]"
✅
명확한 피드백
액션 결과를 즉시, 명시적으로 전달. "저장됨" 표시는 최소 3초 유지.
🧠
기억 의존 최소화
이전 단계 정보를 다음 단계에서 참조할 필요를 없앤다. 멀티 스텝 폼에서 요약 표시.
COGA 실패 사례
CAPTCHA 시각 퍼즐

시각적 퍼즐은 인지 장애 사용자에게 극도로 어렵다. 왜곡된 문자 인식은 학습 장애 사용자에게 불가능에 가까운 과제.

reCAPTCHA v3 (스코어 기반)

사용자 상호작용 불필요. 백그라운드 행동 분석으로 봇 여부 판단. 인지 부하 제로.

복잡한 비밀번호 규칙

"대문자+소문자+숫자+특수문자+8자 이상"은 인지 부하가 높다. 기억 의존도 매우 높음.

패스키 / 생체 인증

지문, 얼굴 인식, 보안 키로 인증. 기억할 내용 없음. 피싱 방지 효과도 있음.

컨텍스트 없는 아이콘

라벨 없는 아이콘은 학습 장애 사용자에게 특히 어렵다. 의미를 기억에 의존하게 만든다.

아이콘 + 텍스트 레이블

아이콘 옆에 항상 짧은 레이블을 둔다. "저장됨" 같은 피드백은 최소 3 초 유지해 놓치지 않게 한다.

Reduced Transparency
투명도 감소

시력이 약하거나 광과민성이 있는 사용자는 반투명 배경 위의 텍스트를 읽기 어렵습니다. iOS "투명도 줄이기" · macOS "투명도 줄이기" 설정이 prefers-reduced-transparency 를 트리거합니다.

기본 vs 감소 — 시각 비교
반투명 오버레이 — rgba(0,0,0,0.5)
불투명 전환 — rgb(30,30,30)

배경 대비가 확보되어 텍스트 판독성이 안정된다

prefers-reduced-transparency CSS
/* 기본: 반투명 배경 */
.overlay {
  background: rgba(0, 0, 0, 0.5);
}

/* 투명도 감소: 불투명 배경 */
@media (prefers-reduced-transparency: reduce) {
  .overlay {
    background: rgb(30, 30, 30);
  }
}

Apple 은 다크 모드에서 사이드바·시트 배경에 반투명을 기본 적용하지만, "투명도 줄이기" 활성 시 불투명 배경으로 자동 전환한다.
