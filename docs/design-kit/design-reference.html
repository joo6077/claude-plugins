# 소스 제목 / 프로덕트 채널 핵심 참고 포인트
1 Dribbble SaaS dashboard minimal design 갤러리 warm neutral 배경 + amber CTA 조합, 카드 그리드 레이아웃
2 Awwwards Clean task management UI 갤러리 화이트스페이스 활용, 타이포 위계 명확, 미니멀 아이콘
3 Linear Issue tracker, 사이드바+리스트 네비게이션 프로덕트 다크 모드 기본, 키보드 중심 UX, 빠른 검색 패턴
4 Notion 블록 에디터, 미니멀 타이포 중심 프로덕트 콘텐츠 우선 레이아웃, 플랫 UI, 부드러운 전환 애니메이션
5 shadcn/ui Button 컴포넌트, 필드/아웃라인/고스트 variant DS variant 패턴 구조, CSS 변수 토큰, Tailwind 통합
