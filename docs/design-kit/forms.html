입력 마스킹

실시간 입력 마스킹 데모

입력 마스크는 타이핑 중 실시간으로 형식을 적용한다. 전화번호, 카드번호, 금액 필드에서 가독성을 높이고 입력 오류를 줄인다.

전화번호

원시값:

010-1234-5678 형식 자동 적용

카드번호

원시값:

4자리마다 공백 자동 삽입

금액

원시값:

천 단위 콤마 + ₩ 접두사

폼 분석

필드 이탈 퍼널 분석

각 필드에서 이탈하는 비율을 퍼널 차트로 시각화하면 병목 필드를 즉시 식별할 수 있다. 이탈률이 높은 필드의 원인을 분류하고 개선한다.

필드별 이탈 퍼널

빨간색 영역일수록 이탈률이 높아 개선이 필요한 필드

핵심 지표 건강 수준

지표건강한 수준개선 신호
완료율 60~80% < 50%이면 UX 문제
필드 이탈률 5% 미만/필드 특정 필드에서 급증 시 검토
필드 소요 시간 필드별 상이 평균 대비 2배 이상이면 혼란
에러율 10% 미만 20% 이상이면 검사 재설계
재시도율 1.2회 이하 1.5회 이상이면 라벨/형식 개선
