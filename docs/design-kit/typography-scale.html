Principles
4가지 타이포그래피 원칙

NNGroup, WCAG, Material Design 3, Apple HIG에서 도출한 핵심 원칙입니다.

계층 구조 3단계 이내

크기, 굵기, 색상 세 축을 조합해 정보 중요도를 전달한다. 제목-본문-캡션 구분이 0.5초 이내에 인지되어야 한다. NNGroup 아이트래킹 연구에서 시각 계층이 명확한 페이지는 47% 더 빠르게 스캔되었다.

시스템 서체 우선

iOS: SF Pro/NY, Android: Roboto Flex, Web: system-ui를 우선 채택하면 렌더링 성능과 일관성을 확보한다. 커스텀 서체 도입 시 FOUT와 CLS 리스크 발생. 한글 서체는 1~5MB에 달한다.

Dynamic Type 존중

사용자가 선택한 텍스트 크기를 반영해야 한다. iOS Dynamic Type, Android sp 단위, 웹 rem 단위가 시스템 글꼴 크기 설정을 자동 반영한다. WCAG 1.4.4는 텍스트 200% 확대를 요구한다.

글꼴 크기는 충분히 크게

모바일 본문 최소 16px(1rem), 데스크톱 본문 16~18px. 좁은(condensed) 서체는 일반 너비 대비 11.2% 더 긴 인지 시간이 소요. 12px 미만은 40세 이상 가독성 급격 하락.

Fluid Typography

이 텍스트는 clamp(1rem, 2.5vw + 0.5rem, 2rem)으로 설정되어 컨테이너 크기에 따라 부드럽게 변합니다. rem 단위를 사용하여 브라우저 글꼴 크기 설정을 존중합니다.

font-size: clamp(2rem, 4vw + 1rem, 3.25rem);
/* 최소 32px, 최대 52px, 뷰포트에 비례하여 변화 */

/* 계산 공식 (600px → 36px, 1400px → 52px) */
뷰포트 계수(v) = 100 * (52 - 36) / (1400 - 600) = 2vw
상대 기준(r) = (600*52 - 1400*36) / (600 - 1400) = 1.5rem

Bad — 줄 높이 부족 + 좁은 자간
타이포그래피 시스템에서 줄 높이와 자간은 가독성에 결정적인 영향을 미칩니다. 이 텍스트는 줄 높이 1.1에 자간 -0.5px로 설정되어 매우 답답하게 느껴집니다. 다음 줄을 추적하기 어렵습니다.
Good — 적절한 줄 높이와 기본 자간
타이포그래피 시스템에서 줄 높이와 자간은 가독성에 결정적인 영향을 미칩니다. 이 텍스트는 줄 높이 1.7에 기본 자간으로 설정되어 편안하게 읽을 수 있습니다. 줄 추적이 자연스럽습니다.
Bad — px 고정 + 12px 미만
font-size: 11px로 고정하면 브라우저 글꼴 크기 설정을 무시합니다. 40세 이상 사용자의 가독성이 급격히 하락합니다. WCAG 1.4.4 위반 가능성이 있습니다.
Good — rem 단위 + clamp()
font-size: clamp(0.875rem, 1vw + 0.5rem, 1rem)으로 설정하면 줌 200%에서도 적절하게 확대됩니다. rem 단위로 사용자 설정을 존중합니다.
