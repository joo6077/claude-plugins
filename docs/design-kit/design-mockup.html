ID 시스템

{컴포넌트명}-{4자리해시} 포맷으로 모든 UI 요소에 유니크 ID를 부여한다. 시안과 구현 사이의 추적성을 보장하며, 피드백 시 정확한 요소를 지칭할 수 있다.

호버 오버레이

토글 버튼으로 ID 표시/숨김을 전환한다. 요소 위에 마우스를 올리면 해당 ID가 툴팁으로 표시되며, 클릭 시 클립보드에 복사된다.

Figma 연동

선택한 시안이나 개별 컴포넌트를 Figma MCP로 전송할 수 있다. 디자이너와 개발자 간 핸드오프를 자동화한다.
