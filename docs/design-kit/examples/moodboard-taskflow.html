다크 모드 우선 설계 근거

TaskFlow의 핵심 사용 시나리오는 장시간 대시보드 모니터링과 태스크 관리다. 다크 모드를 기본값으로 설정하면 눈의 피로를 줄이고, 컬러 액센트의 시인성을 높이며, 모던 SaaS 제품의 기대치에 부합한다. Warm neutral 톤은 순수 회색(#1a1a1a 계열)보다 친근하고, amber 포인트와 자연스러운 조화를 이룬다.

Typography

TaskFlow는 팀의 일상적인 업무 흐름을 최소한의 마찰로 관리하기 위해 설계되었습니다. Sprint 단위로 태스크를 정리하고, Kanban 보드에서 진행 상황을 실시간으로 확인하며, 마감 알림과 자동 우선순위 조정으로 팀원 모두가 같은 맥락을 공유할 수 있습니다.

각 태스크에는 담당자, 마감일, 라벨, 우선순위가 할당됩니다. Subtask 분할과 의존성 연결을 지원하며, 완료된 태스크는 자동으로 Archive로 이동합니다. Keyboard shortcut(Cmd+K)으로 빠르게 검색하고 이동할 수 있습니다.

패턴 선택 대안 선택 근거
레이아웃 사이드바 대시보드 탑바 + 콘텐츠 SaaS 대시보드에서 사이드바는 네비게이션 항목이 많아져도 수직 확장이 가능하고, 메인 콘텐츠의 수평 공간을 최대한 확보한다. 탑바 구조는 모바일에 유리하지만 데스크톱 중심 제품에서는 공간 효율이 떨어진다.
네비게이션 아이콘 + 텍스트 사이드바 탭바 / 아이콘 전용 아이콘만으로는 레이블 학습 곡선이 높아 SaaS 초기 온보딩에 불리하다. 텍스트를 함께 표시하면 직관성이 올라가고, 접힘(collapse) 옵션으로 숙련자 모드도 지원할 수 있다.
카드 스타일 플랫 보더 엘리베이션 (그림자) 다크 테마에서 box-shadow는 시인성이 낮고 시각적 노이즈가 된다. 미세한 보더(1px, low-alpha)로 구분하면 깔끔하면서도 계층 구조를 유지한다. Linear, Vercel 등 레퍼런스 제품도 이 패턴을 사용한다.
버튼 스타일 필드 (Filled) 아웃라인 (Outlined) Primary CTA는 amber filled로 강한 시각적 무게를 부여한다. Secondary는 ghost 또는 outline으로 위계를 분리한다. 다크 배경에서 filled 버튼은 아웃라인보다 클릭 어포던스가 높다.
