UI Patterns

레이아웃

사이드바 대시보드

좌측 고정 네비게이션 + 우측 메인 콘텐츠. 정보 접근성과 넓은 작업 영역 확보.

네비게이션

사이드바

주요 섹션(대시보드, 태스크, 팀, 설정)을 항상 접근 가능하게 노출.

정보 밀도

중간

카드 그리드로 태스크를 요약 표시. 상세 정보는 카드 클릭 후 확인.

카드 스타일

플랫

그림자 없이 미세한 보더로 구분. 미니멀하고 깔끔한 느낌 유지.

버튼 스타일

필드 (Filled)

Primary: amber 배경, Secondary: 투명+보더, Ghost: 배경 없음.

인풋 스타일

아웃라인

보더로 영역을 명확히 표시. 포커스 시 amber 보더로 전환.
