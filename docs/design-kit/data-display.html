☰ 리스트 뷰가 적합한 경우
  • 텍스트 정보가 주요 콘텐츠 (이름, 설명, 가격, 날짜)

구현 규칙
  • 1만 미만: 원래 숫자 표시 (예: 9,876)
  • 1만~1억 미만: 만 단위 (예: 1.2만, 123.5만)
  • 1억~1조 미만: 억 단위 (예: 1.5억, 1,234.6억)
  • 1조 이상: 조 단위 (예: 1.5조)
  • 소수점은 최대 1자리까지만
  • 금액(₩)은 "약" 접두사 고려: "약 1.2억원"
  • 정확한 값이 필요한 맥락(결제, 잔고)에서는 축약하지 않는다
