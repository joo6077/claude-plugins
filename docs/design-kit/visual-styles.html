Visual Reference v1.0

UI 비주얼 스타일
카탈로그 -- 35종

Design Morphisms · Surface Treatments · Visual Paradigms

웹과 앱 UI에서 사용되는 35가지 비주얼 스타일을 순수 CSS로 구현한 레퍼런스 카탈로그입니다. 각 카드의 데모 영역은 해당 스타일의 핵심 시각 특성을 보여줍니다.

Category A
핵심 Morphism 계열

사물의 표면, 깊이, 재질을 CSS로 표현하는 핵심 형태학적 스타일 9종. 스큐어모피즘에서 시작해 글래스, 클레이, 뉴모피즘까지 UI 표면의 진화를 담고 있습니다.
