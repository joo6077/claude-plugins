01

아키텍처 개요

design-kit 템플릿은 3계층으로 구성됩니다. 리서치 문서가 콘텐츠를 공급하고, base.html이 공통 인프라를 제공하며, 각 산출물 스킬 템플릿이 최종 결과물을 만들어냅니다.

Layer 1

Foundations 리서치

design-kit/docs/design/

색상 이론, 타이포그래피, 스페이싱, 애니메이션 원칙 등 디자인 원칙 문서. 스킬이 이 레퍼런스를 읽어 산출물의 방향성과 콘텐츠를 결정합니다.
›
Layer 2

base.html

design-kit/templates/base.html

모든 산출물이 공유하는 CSS 변수 체계, 반응형 레이아웃, 다크/라이트 토글, 한/영 i18n을 제공하는 공통 골격. 스킬 템플릿은 이 구조를 복사해 시작합니다.
›
Layer 3

산출물 템플릿 × 4

moodboard / catalog / mockup / component

각 스킬이 사용하는 특화 템플릿. base.html의 토큰과 클래스를 상속하면서 고유한 섹션과 플레이스홀더를 추가합니다.
📁 파일 구조
design-kit/ ├── templates/ │ ├── base.html ← 공통 CSS 변수 + 툴바 + i18n 스크립트 │ ├── moodboard.html ← design-concept 스킬 산출물 │ ├── catalog.html ← design-reference 스킬 산출물 │ ├── mockup.html ← design-mockup 스킬 산출물 │ └── component.html ← design-component 스킬 산출물 └── docs/design/ ├── color-theory.md ├── typography.md └── ...
02

base.html — 공통 골격

모든 산출물 템플릿의 기반. 반응형 레이아웃, 다크/라이트 모드, 한/영 i18n 세 가지 기능이 기본 내장되어 있습니다. 스킬 템플릿은 base.html의 CSS 변수와 클래스를 그대로 사용합니다.

📱
반응형 레이아웃
clamp() 기반 타이포그래피와 스페이싱으로 모바일(320px)부터 데스크톱(1440px+)까지 단일 CSS로 대응합니다. .base-grid, .base-page가 핵심 레이아웃 클래스.
🌑
다크 / 라이트 모드
data-theme="dark|light"로 전환하며 localStorage에 사용자 설정을 저장합니다. 시스템 설정도 자동 감지하며 @media prefers-color-scheme 폴백 포함.
🌐
한/영 i18n
data-i18n="키" 속성과 T = {ko:{}, en:{}} 딕셔너리 객체 방식. 언어 전환 시 DOM을 자동 업데이트하며 localStorage에 언어 설정을 저장합니다.
CSS 변수 체계
모든 색상, 타이포, 스페이싱, 레이아웃을 변수로 관리합니다. 스킬 템플릿은 이 변수들을 오버라이드해 프로젝트 팔레트를 적용합니다.
컬러 토큰
--color-bg
페이지 배경 (라이트: #ffffff, 다크: #121212)
--color-surface
카드·패널 배경 (배경보다 한 단계 높음)
--color-surface-high
호버·포커스 상태용 높은 표면
--color-text-primary
주 텍스트 (제목, 본문)
--color-text-secondary
보조 텍스트, 설명 문구
--color-text-tertiary
비활성·캡션 텍스트
--color-border
구분선, 카드 테두리
--color-accent
브랜드 강조색 (링크, 버튼, 포커스 링)
--color-accent-soft
강조색 10% 배경 (뱃지, 태그)
타이포그래피 토큰
--text-xs ~ --text-3xl
clamp() 기반 6단계 폰트 사이즈 스케일
--font-family
Pretendard Variable + 시스템 폰트 폴백
스페이싱 토큰
--space-xs ~ --space-2xl
clamp() 기반 6단계 간격 스케일 (4px–80px)
--content-max
콘텐츠 최대 너비: 1200px
--radius-sm / -md / -lg
6px / 10px / 16px — 모서리 반경 3단계
유틸리티 클래스 목록
base.html이 제공하는 기본 클래스. 스킬 템플릿이 이 클래스들을 활용합니다.

.base-h1 ~ .base-h4

.base-subtitle
text-lg 보조 제목 텍스트
.base-caption
text-sm tertiary 캡션
.base-btn
border 스타일 기본 버튼
.base-btn-primary
accent 배경 주 CTA 버튼
.base-input
포커스 링 + 테두리 인풋
.base-tag
accent-soft 배경 뱃지 태그
.base-toolbar

04

커스터마이징 방법

스킬이 산출물을 생성할 때 적용하는 세 가지 커스터마이징 포인트. CSS 변수 오버라이드, 섹션 조작, i18n 딕셔너리 수정 순서로 진행합니다.

1
CSS 변수 오버라이드 — 프로젝트 팔레트 적용
:root 블록에서 --color-accent, --color-bg 등을 프로젝트 팔레트로 교체합니다. moodboard.html의 경우 --mb-primary ~ --mb-surface2 변수를 추가로 채웁니다.
/* :root 안에 추가 */ --color-accent: #4f46e5; --color-accent-soft: rgba(79, 70, 229, 0.1); /* moodboard 전용 팔레트 */ --mb-primary: #4f46e5; --mb-secondary: #7c3aed; --mb-accent: #a78bfa;
2
섹션 추가 / 제거 — 필요한 부분만 유지
각 <section> 블록은 독립적으로 제거할 수 있습니다. 사이드바 메뉴가 있는 component.html은 해당 nav 항목도 함께 제거해야 합니다. {{SECTION_PLACEHOLDER}} 주석이 있는 위치에 새 섹션을 삽입합니다.
<!-- 불필요한 섹션 제거 시 --> <!-- <section class="spec-section" id="sizes"> ... </section> --> <!-- 새 섹션 추가 --> <section class="spec-section" id="animation"> <h2 class="spec-section-title">애니메이션</h2> <!-- ... --> </section>
3
i18n 딕셔너리 수정 — 한/영 텍스트 채우기
페이지 하단 <script> 안의 T = {ko:{}, en:{}} 객체에서 {{PLACEHOLDER}} 값들을 실제 텍스트로 교체합니다. HTML의 data-i18n="키" 속성과 딕셔너리 키가 일치해야 합니다.
const T = { ko: { toolbar: { title: '프로젝트 이름 무드보드' }, hero: { title: '프로젝트 이름', concept: '대담하고 신뢰감 있는' }, }, en: { toolbar: { title: 'Project Moodboard' }, hero: { title: 'Project Name', concept: 'Bold & Trustworthy' }, } };
05

조합 가이드

visual-styles.html 등 foundations 리서치 데이터를 스킬 산출물에 연결하는 방법. 각 템플릿은 어떤 리서치 데이터를 어떤 방식으로 활용하는지 설명합니다.

moodboard visual-styles 참조 데이터 활용
visual-styles.html의 컬러 팔레트 시각화 데이터를 moodboard의 팔레트 섹션으로 옮기는 워크플로우.
1
visual-styles.html에서 Primary, Secondary, Accent hex 값 추출
2
--mb-primary ~ --mb-surface2 CSS 변수에 적용
3
스와치 {{COLOR_PRIMARY_NAME}}, {{COLOR_PRIMARY}}에 이름 + hex 채우기
4
Hero 배경 그라디언트에 var(--mb-primary) 참조로 자동 반영
component 디자인 토큰 매핑
design-system 스킬이 생성한 토큰 체계를 component.html의 토큰 섹션에 연결하는 방법.
1
design-system 산출물의 CSS 변수 목록 추출
2
{{TOKEN_1~N}}에 해당 컴포넌트가 사용하는 변수만 필터링해 삽입
3
라이브 프리뷰 HTML에 동일한 CSS 변수 참조로 실시간 테마 전환 확인
4
[data-theme="dark"] 오버라이드로 다크 모드 토큰 검증
mockup 멀티 컨셉 조합 전략
moodboard에서 검증된 컬러 + catalog에서 수집된 레퍼런스를 mockup의 컨셉 A/B/C로 변환.
1
moodboard 팔레트에서 컨셉별 Primary 컬러 선택 → {{COLOR_A~C}}
2
catalog 인사이트 → {{CONCEPT_N_DESC}} 근거 문장에 반영
3
각 컨셉 {{TAGS_N}}에 catalog의 인사이트 키워드 활용
4
피드백 섹션 결과를 다음 iteration moodboard에 반영
catalog 레퍼런스 카드 배치 전략
레퍼런스 수가 많을 때 카테고리 필터와 인사이트 카드를 효과적으로 구성하는 방법.
1
레퍼런스 카드에 data-category 속성으로 분류 (Navigation, Hero, Card…)
2
