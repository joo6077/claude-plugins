무드 키워드

프로젝트의 시각적 분위기를 정의하는 3~5개 키워드. 각 키워드에 한 줄 설명을 붙여 팀 공유 언어를 만든다.

컬러 방향

베이스 톤, 채도 레벨, 포인트 컬러, 다크/라이트 모드 우선순위를 자연어로 기술한다.

타이포 방향

폰트 패밀리, 분류(serif/sans/mono), 웨이트 단계, 제목-본문 크기 비율을 정의한다.

UI 패턴

네비게이션 구조, 카드/리스트 스타일, 버튼/입력 필드 형태 등 핵심 UI 패턴을 나열한다.

레퍼런스

영감을 받은 프로덕트, 디자인 시스템, 시각 자료의 URL과 간단한 메모를 기록한다.
