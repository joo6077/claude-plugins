Step 1
Flutter 프로젝트 확인
pubspec.yaml을 찾아 패키지명과 SDK 버전을 추출한다. 없으면 에러를 출력하고 중단한다.
추출 항목
name → 패키지명 (package:{name}/... import 경로)
environment.sdk → Dart SDK 버전 제약
미감지 시 에러
"Flutter 프로젝트가 아닙니다. pubspec.yaml이 있는 디렉토리에서 실행해주세요."
Step 2
SDK 매니저 감지
프로젝트 루트의 설정 파일로 SDK 매니저를 판별하고 명령 prefix를 결정한다.
.fvmrc 또는 .fvm/fvm_config.json
FVM
fvm flutter / fvm dart
.tool-versions (asdf flutter 항목)
asdf
flutter / dart
설정 파일 없음
System
flutter / dart
감지 결과 변수 FVM → $FLUTTER = fvm flutter   $DART = fvm dart
기타 → $FLUTTER = flutter     $DART = dart
Step 3
의존성 감지
pubspec.yaml의 dependencies + dev_dependencies에서 패키지를 감지하고 플래그를 설정한다.
패키지감지 플래그영향받는 스킬
flutter_riverpod / hooks_riverpodHAS_RIVERPODflutter-provider
go_routerHAS_GO_ROUTERflutter-screen, flutter-transition
go_router_builderHAS_GO_ROUTER_BUILDERflutter-screen (TypedGoRoute)
freezedHAS_FREEZEDflutter-api, flutter-feature
retrofitHAS_RETROFITflutter-api
build_runnerHAS_BUILD_RUNNERflutter-run (codegen)
slang / slang_flutterHAS_SLANGflutter-l10n
easy_localizationHAS_EASY_L10Nflutter-l10n
flutter_hooks / hooks_riverpodHAS_HOOKSflutter-hooks, flutter-widget
custom_lintHAS_CUSTOM_LINTflutter-audit
auto_routeHAS_AUTO_ROUTEflutter-screen, flutter-transition
flutter_bloc / blocHAS_BLOCflutter-provider, flutter-audit
dioHAS_DIOflutter-api
미설치 패키지 안내
"{패키지}가 pubspec.yaml에 없습니다. 이 기능을 사용하려면 먼저 설치해주세요:
$FLUTTER pub add {패키지}"
Step 4
아키텍처 패턴 감지
lib/ 디렉토리 구조를 분석하여 프로젝트 아키텍처를 판별한다.
ARCH = clean
lib/features/*/data/
lib/features/*/domain/
lib/features/*/presentation/
domain → data, presentation import 금지
Repository: interface(domain) + impl(data) 분리
ARCH = mvvm
lib/features/*/ui/
lib/features/*/view_models/
lib/*/views/, lib/*/view_models/
View ↔ ViewModel 1:1 관계
Repository → Service 레이어 분리
ARCH = feature_first
lib/features/*/
(data/domain/presentation 없음)
ARCH = flat
lib/src/
또는 flat 구조
