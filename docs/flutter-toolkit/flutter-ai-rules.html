2 · State

State Management — 공식 우선순위

서드파티 패키지가 없을 때의 공식 순서다. 프로젝트에 Riverpod/Bloc 이 있으면 해당 패키지 패턴을 따른다.

1
ValueNotifier + ValueListenableBuilder — 단일 값
2
Stream + StreamBuilder — 비동기 이벤트 시퀀스
3
Future + FutureBuilder — 일회성 비동기
4
ChangeNotifier + ListenableBuilder — 복합/다중 위젯 상태
5
MVVM 패턴 — 복잡한 앱
프로젝트에 Riverpod/Bloc 이 이미 있으면 해당 패키지 패턴을 따른다. 위 순서는 서드파티 없이 프레임워크만으로 상태를 다룰 때의 기본값이다. 상세는 상태 관리 문서 참조.

4 · Do's & Don'ts

해야 할 것 vs 하지 말 것

공식 rules 의 명시적 목록. 코드 생성 시 그대로 적용한다.

Do
  • go_router 네비게이션 (딥링크, 웹 지원)
  • SOLID 원칙
  • dart:developer.log 사용
  • compute() 사용 (비용 큰 연산은 Isolate)
  • 모든 public API 에 /// 문서화
  • dart_format, dart_fix 도구 활용
  • 다양한 화면 크기 테스트
Don't
  • print() 사용 금지 → dart:developer.log
  • build() 내 네트워크 호출 금지
  • 같은 Row/Column 에 Flexible + Expanded 혼용 금지
  • ! 연산자 남용 금지 (non-null 보장된 경우만)
  • 깊은 위젯 트리 중첩 금지 → 합성으로 분해

6 · Riverpod 3.0

2026 생태계 — Riverpod 3.0

Notifier 라이프사이클과 legacy provider 정리. 모든 항목에 출처 URL 이 있다.

Ref.mounted 공식 패턴

disposed Notifier 접근 시 에러를 throw 한다. async 메서드 끝에 if (!ref.mounted) return; 이 필수다.

riverpod.dev/docs/whats_new

Notifier 재생성 라이프사이클

2.x 의 pseudo-singleton 이 폐기됐다. Timer/StreamSubscription/Controller 를 Notifier 필드로 유지하면 리소스가 누수된다. 별도 provider + ref.onDispose 로 분리한다.

riverpod.dev/docs/3.0_migration

legacy provider 정리

StateNotifierProvider / StateProvider / ChangeNotifierProvider 는 legacy 다. 신규 코드는 @riverpod / Notifier 기반으로 작성한다.

pub.dev/packages/flutter_riverpod/changelog

Ref 타입 파라미터 제거 · 알림 필터링 · valueOrNull

  • FutureProviderRef 등 subclass 가 전부 삭제되고 Ref 를 직접 쓴다.
  • == 기반 알림 필터링 — StreamProvider/StreamNotifier 의 동등성 이벤트는 listener 에 전달되지 않는다. 모델의 operator == / hashCode 정의가 알림 동작을 결정한다.
  • .valueOrNull → .value 로 변경. dart fix --apply 로 자동 마이그레이션 가능.
riverpod.dev/docs/3.0_migration
7 · Freezed 3.0

Freezed 3.0 — when/map 은 영구 제거가 아니다

이번 사이클에 정정된 항목이다. 과거 요약(".when/.map 제거")은 사실이 아니다.

클래스 선언 형태가 강제된다

@freezed abstract class (단일) / @freezed sealed class (union) 가 필수다. factory 생성자만 있는 class 는 이제 abstract 또는 sealed 여야 한다.

pub.dev/packages/freezed/changelog

union 분기 — pattern matching 권장, when/map 은 살아 있다

union 분기는 Dart pattern matching (switch expression) 을 신규 코드에서 권장한다. 단 .when / .map 이 영구 제거된 것은 아니다 — 3.0 에서 제거됐다가 3.1.0 에서 다시 추가됐고 최신 stable 은 3.2.5 다. 기존 코드가 generated when/map 을 쓰면 일관성을 유지한다.

pub.dev/packages/freezed/changelog

컬렉션 · 어노테이션 변경

  • List / Map / Set 은 UnmodifiableListView / UnmodifiableMapView / UnmodifiableSetView 로 자동 변환된다.
  • @With / @Implements 문법이 generic annotation 기반으로 변경됐다.
pub.dev/packages/freezed/changelog
정정 이력 — "3.0 에서 .when/.map 제거 → pattern matching 사용" 이라는 요약은 3.1.0 의 재추가를 반영하지 못한 낡은 서술이었다. 마이그레이션을 강제하기 전에 pubspec.lock 의 freezed 버전을 확인하라.

10 · Hooks & Monorepo

flutter_hooks · Makefile 기반 monorepo 관습

hooks + Riverpod 통합과, 실행 옵션을 Makefile 에 집중하는 관습.

flutter_hooks

  • HookConsumerWidget 으로 hooks + Riverpod provider 를 통합한다.
  • useMemoized + useEffect 조합으로 데이터 페칭 중복을 방지한다.
  • useEffect cleanup 은 반환 함수로 등록한다 — 위젯 dispose / 의존성 변경 시 호출된다.
riverpod.dev/docs/concepts/about_hooks pub.dev/packages/flutter_hooks

Makefile 기반 monorepo (fit-pal / apps)

  • dart-define-from-file=.dart_defines.json, --observatory-port=8181 등 실행 옵션을 Makefile 타겟에 집중한다.
  • 직접 fvm flutter run 을 호출하면 환경 누락으로 다른 플레이버가 기동될 위험이 있다.
  • flutter-preflight / flutter-run 스킬은 HAS_MAKEFILE = true 감지 시 make <target> 을 우선한다.

12 · Gotchas

Gotchas 체크리스트

버전 사실 확인, legacy API, 리소스 누수.

  • ✓
    Freezed .when/.map 을 "제거됨" 으로 단정하지 마라 3.0 에서 제거됐다가 3.1.0 에서 다시 추가됐다. 최신 stable 은 3.2.5 다. 마이그레이션을 강제하기 전에 pubspec.lock 을 읽어라.
  • ✓
    Impeller 는 플랫폼마다 상태가 다르다 iOS 필수 · Android API 29+ 기본 · 데스크톱은 Flutter 3.47 부터 기본 · Web 은 Skia. "Android 는 opt-in" 같은 과거 서술을 그대로 옮기지 마라.
  • ✓
    Notifier 필드에 Timer/Subscription 을 들고 있지 마라 Riverpod 3.0 에서 Notifier 는 재생성된다. 별도 provider + ref.onDispose 로 분리하지 않으면 리소스가 누수된다.
  • ✓
    모델의 == 정의가 알림 동작을 바꾼다 Riverpod 3.0 은 == 기반으로 알림을 필터링한다. operator ==/hashCode 를 잘못 정의하면 listener 가 이벤트를 못 받는다.
  • ✓
    Makefile 프로젝트에서 직접 fvm flutter run 하지 마라 dart-define 파일과 포트 옵션이 누락되어 다른 플레이버가 기동될 수 있다. make <target> 을 우선한다.
Summary

한 문장 요약

공식 rules + 버전 사실 확인이 함께 가야 한다

합성·private 위젯·const·go_router·dart:developer.log 같은 공식 rules 는 그대로 따르되, 생태계 항목은 버전 사실을 매번 확인한다. Freezed 의 .when/.map 은 3.1.0 에서 되살아났고, Impeller 는 플랫폼마다 상태가 다르며, 2026-08 기준 stable 은 3.47.0 이다. 과거 요약을 그대로 옮기는 것이 이 문서에서 가장 흔한 결함이다.
