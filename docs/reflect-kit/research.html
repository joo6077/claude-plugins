반복 실수 탐지 스택

regex + sequence + embedding + LLM

단계방법역할
1 (기본선)키워드 매칭tool failure, "아니", "다시", "그 뜻이 아니고", "파일 경로", "권한"
2sequence pattern실패 → 사용자 교정 → 재시도 성공 2~4턴
3embedding clustering같은 의미 다른 표현 묶기
4LLM 분류클러스터 라벨링, surface 추천, contract 초안
regex only = recall 낮음. LLM only = 비쌈. regex/sequence prefilter + embedding cluster + LLM adjudication 3단 조합이 현실적.
reflect-kit 초기 구현은 "LLM 직접 분류(codex exec)"로 시작 — 데이터 쌓이면 보조안으로 진화.
