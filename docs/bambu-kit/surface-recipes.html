2.7. 형상 클래스 — planar vs thin (2026-09-08 신규)

§3 의 속도표는 소재 축만 갖는다. 2026-09-07 래티스 통(ABS · 0.12mm High Quality @BBL H2S) 실측에서 같은 surface-first 값이 큰 평면(Funnel)과 스트럿 단면(Side Container)에 똑같이 들어갔고, 결함 원인은 flow · PA · Z · 워핑 · 습기가 아니라 속도값과 냉각 문턱이었다. 얇은 단면의 병목은 유량이 아니라 열 방출 시간이라 느릴수록 나빠진다. 그래서 형상 축을 §2.4 "얇은 벽 / 미세 디테일" 분기에 측정으로 붙인다 — 키워드 추측이 아니라 단면 루프 둘레로 판정한다.

SKILL.md Phase 1.0 의 geometry-class probe 블록이 3mf 메시를 빌드 좌표에서 높이 25 / 50 / 75 % 로 절단해 오브젝트별 루프 수 · 둘레 · < 30 mm 비율 · _geometry_class 를 출력한다. 결과는 process JSON 에 _geometry_class (planar | thin) 와 _thin_loop_share 로 기록하고 Phase 4.3 게이트가 이를 읽는다.

임계 근거

30 mm 와 비율 0.5

30 mm 는 seam-recipes.md §2.2 의 scarf off 임계와 같은 값이다. 그 아래에서는 램프가 루프를 지배한다는 실측(둘레 32 mm 루프에 8 mm 램프로 세로 파임, 2026-09-05)과, 래티스 스트럿 단면 둘레가 5.3~20.6 mm 에 몰린다는 실측(2026-09-07)이 같은 경계를 가리킨다.

비율 0.5 는 "레이어의 절반 이상이 스트럿 단면" 이면 그 레이어의 열 거동을 스트럿이 결정한다는 뜻이다.

thin 의 유량비 게이트: thin 에서 유량비 게이트는 부모 실효값으로 계산한다 — 0.12mm High Quality @BBL H2S 는 gap_infill_speed 230 대 outer_wall_speed 60 으로 3.8x 경고 구간이며, 이 경고는 정보 보고이지 외벽 하향 사유가 아니다. 인접 키를 외벽 쪽으로 낮추는 것은 허용하지만 외벽을 내리지는 않는다. 냉각 보상 키의 이름 · 스코프 · 실효값 정본은 bambu-fields-baseline.md §10.5 다.

2.8. 벽 예산 — 피처 폭이 벽을 못 담으면 갭필로 샌다 (2026-09-14 신설)

구멍 · 빈 칸이 있는 부품은 형상 클래스(§2.7)와 무관하게 한 가지를 더 계산한다. 벽이 실제로 들어가는지다. 처음에는 thin 에서만 계산했는데, 2026-09-19 전부 planar 로 판정된 부품에서 같은 결함이 났다 (아래 실측).

계산식

벽 두 겹이 들어갈 최소폭

벽 예산 = outer_wall_line_width x 2 + inner_wall_line_width x 2 x (wall_loops - 1)

0.12mm High Quality @BBL H2S 실효값(외 0.42 · 내 0.45 · wall_loops 2) 기준 1.74 mm 다.

피처의 국소 최소폭이 이 값보다 작으면 벽 두 겹이 안 들어간다. 중앙값이나 수력직경으로 재면 안 된다 — 결함은 가장 좁은 자리에서 난다. 회전 캘리퍼로 루프별 최소 두께를 재라.

측정

부족 둘레 비율 _wall_budget_short_share

SKILL.md Phase 1.0 형상 측정을 WALL_LOOPS=<벽 수> OUTER_LINE_WIDTH=<외벽 선폭> INNER_LINE_WIDTH=<내벽 선폭> 과 함께 돌린다. 부품마다 루프 위 점에서 다른 루프까지의 거리를 재서, 벽 예산보다 좁은 둘레 비율을 바닥 0.1 mm · 25 · 50 · 75 % 높이에서 낸다.

마지막 줄의 _wall_budget_short_share(전 부품 최댓값)를 process JSON 에 기록하면 Phase 4.3 게이트가 classic 과 함께 10 % 이상일 때 FAIL 한다. 10 % 는 추정이다 — 결함이 난 실측은 22~90 %, 결함이 없던 부품은 0 % 였다.

비율은 둘레 길이로 센다. 점 수로 세면 메시가 잘게 쪼개진 곡선 구간이 부풀어, 같은 뒤쪽 브래킷이 72.0 % 대신 58.8 % 로 나온다 (2026-09-19 두 방식 대조). 같은 루프 안에서 윤곽이 접혀 들어온 좁은 목은 재지 않는다.

Section 03

3. 외벽 표면 권장값 (공통)

H2S 0.4 hardened nozzle 기준. 모든 단위 명시.

이 표가 속도·가속 값의 정본(SSOT)이다. seam-recipes.md 는 seam 전략만 갖고 속도는 여기를 참조한다. 두 문서에 같은 소재의 속도 범위를 따로 적지 마라 — 2026-08 superlube 회귀가 그 불일치에서 나왔다.
⚠️ 단일 값이 아니라 유량비로 판정한다. outer 만 낮추는 것은 surface-first 가 아니다. 인접 feature 의 Q 비율이 3x 이하인지 확인하라 (SKILL.md §유량비 게이트).
⚠️ 형상 클래스가 thin 이면 아래 표의 속도 행(outer_wall_speed · inner_wall_speed · internal_solid_infill_speed · sparse_infill_speed · gap_infill_speed)과 §4 의 top_surface_speed 를 적용하지 않는다 — §2.7. 부모 실효값을 그대로 두고 냉각으로 보상한다. 이 표는 planar 전용이다.

5. Ironing 형상×소재 매트릭스

Section 06

6. 트레이드오프

surface-first 모드를 켜면 발생하는 비용. 모든 사용자에게 사전 고지 필수.

6.1

표면 vs 치수

낮은 outer speed + scarf + ironing + flow 조정은 외관 ↑하지만:

Sharp corner / edge sharpness 흐려짐

작은 hole 내경 영향 (Contour and Hole 모드 켜면 더 심함)

얇은 벽에서 wall 3-4겹 적용 시 형상 깨짐

6.2

표면 vs 강도

inner-outer-inner wall sequence는 외관 ↑하지만 일부 형상에서 벽 접합/overhang 안정성 변화

scarf ramp 구간은 layer 강도 미세 변화

낮은 cooling fan은 광택 ↑하지만 PLA 층간 접착 ↓ 가능

6.3

표면 vs 실패 확률

PETG / PC / TPU ironing은 blob, drag mark, clog / heat creep 위험 ↑

Smart scarf가 angle/overhang에서 끊기면 표면 불균일 — Off 또는 threshold 낮춤 필요

PA-CF / PAHT-CF의 0.4mm hardened nozzle은 0.6mm 권장 소재에서 막힘 위험

6.4

표면 vs 시간 / 소재

출력 시간 2~4배 (예: 4시간 → 12시간)

top_shell 7-9 layers, wall 3-4, calibration coupons → 소재 소모 ↑

6.5

속도 무시 시 부작용

속도 무시는 사용자 명시 요구지만, 너무 느리면:

PETG / PC / ABS: 열 축적 → warping, 광택 불균일, stringing 누적 시간 ↑

외벽 50mm/s 미만에서 chamber 온도 관리 필수 (특히 ABS/ASA enclosure)

0.04mm 같은 극단적 fine layer는 nozzle ooze 누적 → blob 위험 ↑

얇은 단면(_geometry_class: thin): 느릴수록 열 방출 시간이 늘어 스트럿이 뭉개진다 — §2.7. 속도 무시 정책은 planar 에만 적용한다

Bad
  • 회전체에 random 을 default 로 둔다 — seam 한 줄을 표면 전체 specks 로 바꿀 뿐이다 (§2.1)
  • PETG 를 PLA 와 같은 저속 그룹에 묶어 outer 30 (§3)
  • outer 만 낮추고 인접 feature 는 스톡 그대로 — 유량비가 5x 를 넘는다 (§3)
  • thin 부품에도 §3 속도 하향 — 외벽 60 → 30 이 두 문턱을 악화시켰다 (§2.7)
  • 벽 예산보다 좁은 피처를 classic 로 자른다 — 갭필 253.0 m (§2.8)
  • bridge_speed 를 안 써서 H2S 부모 50 이 남는다 (§4)
  • wall_loops 2 에 inner-outer-inner wall (§3)
  • enable_arc_fitting · resolution 0.008 을 표면 품질 카드로 제시 (§3)
  • OrcaSlicer 문서의 ironing enum 이름을 그대로 쓴다 — 에러 없이 무시된다 (§5)
  • ABS 윗면에 다림질을 자동으로 켠다 — 윗면 길이의 2.7 배를 지나갔다 (§5.1)
Good
  • vase 가능이면 spiral_mode = 1 + spiral_mode_smooth = 1, 아니면 aligned/back + seam paint + 짧은 scarf (gap 0)
  • PETG HF outer 50-70 + AMS HT 65°C 8h 사전 건조 + continuous drying
  • 인접 feature 의 Q 비율이 3x 이하인지 확인 (SKILL.md §유량비 게이트)
  • 부모 실효값을 두고 filament 스코프 overhang_fan_threshold 로 냉각 보상
  • wall_generator 를 arachne 로 — 갭필 0.4 m
  • _geometry_class 를 기록한 프로파일은 bridge_speed 20-30 을 같이 쓴다
  • inner-outer-inner wall 은 wall_loops >= 3 일 때만
  • 기본값 유지 (1 · 0.012) — failure-recipes.md §1.2
  • 설치본에서 값을 확인하고 Phase 4.3 게이트의 enum allowlist 로 잡는다
  • 기본 no ironing, 실물 비교 뒤 요청하면 topmost

  • ✓회전체는 vase 가능 여부부터 본다. random 은 fallback 전용이고 surface-first default 아님.
  • ✓속도·가속 값의 정본은 §3 표다. seam-recipes.md 에 같은 소재의 속도 범위를 따로 적지 마라.
  • ✓outer 만 낮추는 것은 surface-first 가 아니다. 인접 feature 의 Q 비율 3x 이하를 확인한다.
  • ✓_geometry_class 와 _thin_loop_share 를 process JSON 에 기록한다. thin 이면 §3 속도 행과 top_surface_speed 를 적용하지 않는다.
  • ✓구멍 · 빈 칸이 있는 부품은 형상 클래스와 무관하게 벽 예산을 계산한다. 비율은 둘레 길이로 센다.
  • ✓형상을 잰 프로파일은 bridge_speed 를 반드시 같이 쓴다. 압출기 슬롯 하나만 높아도 게이트가 잡는다.
  • ✓PETG HF 는 AMS HT 65°C 8h, PA-CF / PAHT-CF 는 AMS HT 80°C 8h 건조 + hardened nozzle.
  • ✓inner-outer-inner wall 은 wall_loops >= 3 을 전제한다.
  • ✓layer_height 0.08 은 시간 배수를 고지하고 선택을 받은 뒤에만 — 자동으로 밀어넣지 마라.
  • ✓enable_arc_fitting · resolution 은 Z 계단 해결책이 아니다.
  • ✓ironing · top_surface_pattern enum 은 Bambu 이름을 설치본에서 확인한다.
  • ✓ABS / ASA ironing 은 기본 끔. 다림질이 결함 원인인지는 아직 [추정] 이다.
  • ✓G-code 수치를 다시 잴 때는 SKILL.md Phase 4.4 「G-code 로 길이 재기」 블록으로 재고 호 비율을 같이 적는다.
  • ✓실측 실패 뒤에는 이 파일(사전 정책)이 아니라 failure-recipes.md (사후 대응) 로 간다.
