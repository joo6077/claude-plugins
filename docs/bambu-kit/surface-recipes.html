2.1 회전체 / 원기둥 / 컵 / 화병 — v4

회전체 감지
├─ vase 가능 → spiral_mode = 1 + spiral_mode_smooth = 1 (H2S timelapse 끔)
├─ 숨길 면 → aligned/back + seam paint + 짧은 scarf (gap 0)

2.7 형상 클래스 — planar vs thin (2026-09-08 신규)

메시를 높이 25/50/75%에서 절단해 단면 루프로 판정한다. 얇은 단면은 열 방출 시간이 병목이라 느릴수록 나빠질 수 있다.

클래스 판정 속도 냉각
planar <30mm 비율 중앙값 <0.5 §3 + 유량비 gate base
thin 같은 비율 ≥0.5 외벽·인접 4키·top을 쓰지 않고 부모값 확인 후 overhang_fan_threshold만
기록: _geometry_class, _thin_loop_share. 30mm는 scarf off 임계, 0.5는 레이어 절반 이상을 스트럿이 지배한다는 뜻이다.
오브젝트 루프 25/50/75% <30mm 중앙값 최대 둘레 클래스
Side Container LHS V1 52/25/20 1.00 20.6mm thin

Rear Container V2 4/42/55 0.95 338.7mm thin
Funnel V1 2/2/2 0.00 175.5mm planar

실측: 층시간 8.6~14.6s가 ABS 12s를 넘나들고 미지지율 20°=10.4%, 40°=24.0%가 fan threshold 25% 미만이었다. outer 60→30은 악화. 부모 gap 230 / outer 60 = 3.8x는 정보 경고다.

2.8 벽 예산 — 피처 폭이 벽을 못 담으면 갭필로 샌다 (2026-09-14 신설)

벽 예산 = outer line width × 2 + inner line width × 2 × (wall loops - 1)
0.42 × 2 + 0.45 × 2 × (2 - 1) = 1.74mm

WALL_LOOPS, OUTER_LINE_WIDTH, INNER_LINE_WIDTH를 넣고 국소 최소폭을 잰다. 바닥 0.1mm와 25/50/75%에서 다른 루프까지 거리의 부족 둘레 길이를 계산한다. _wall_budget_short_share가 classic과 함께 10% 이상이면 FAIL. 10%는 추정, 결함 실측 22~90%, 무결함 0%다. 점 수가 아닌 둘레 길이로 세며 같은 루프 안의 접힌 목은 제외한다.

국소 최소폭 상태 처방
≥ 벽 예산 정상 유지
< 예산, ≥ 외벽 2겹 0.84mm 벽 못 들어감 arachne
<0.84mm 한 겹도 불가 모델 문제 보고
2026-09-14 래티스

56~90% 부족. classic 갭필 16,123·외벽 18,267·선폭 0.076~0.697mm. Arachne 갭필 0·외벽 9,875.

8. 검증 사례 / 출처

Gotchas 체크리스트

  • ✓ 앱과 번들 버전을 따로 조회한다.
  • ✓ vase부터 보고 random은 마지막 fallback.
  • ✓ scarf gap은 0.
  • ✓ 형상 class와 thin share를 기록한다.

  • ✓ 벽 부족은 둘레 길이로 센다.
  • ✓ 형상 측정 profile은 bridge 20-30.
  • ✓ PETG 65°C 8h, PAHT-CF 80°C 8h.
  • ✓ wall<3이면 inner-outer-inner 금지.
