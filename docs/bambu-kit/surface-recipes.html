Section 1 — 모드 개요

Surface-first 모드는 사용자가 표면 품질을 명시적으로 우선하는 경우 ON. 속도와 시간은 무시하지만, 너무 느린 PETG/PC/ABS에서 열 축적 → warping/광택 불균일 같은 부작용은 별도 관리한다.

Rule 01

트리거 조건

"표면 매끈하게", "심 안 보이게", "완벽한 표면", "퀄리티 우선", "속도 신경 안 씀" 같은 명시 표현. 모델이 외관 prototype / 피규어 / 장식품 / 케이스 외관 / 회전체 화병·컵이면 자동 ON 제안.
Bambu Studio v2.6.0 Release
Rule 02

우선순위

seam 은닉 ≥ 외벽 매끈 > top 마감 > 강도/치수 > 시간. 속도는 무시하되 PETG/PC/ABS의 열 축적 부작용은 별도 관리. 안전성(PETG 건조, CF hardened nozzle)은 항상 우선.
Bambu PETG HF Guide
Rule 03

출력 시간 예상

일반 0.20mm Standard 대비 약 2~4배 증가. 예: 4시간 → 12시간. 0.12mm layer + outer 30mm/s + wall 3 + ironing의 누적 결과. 사용자에게 시간 추정치 사전 고지.
OrcaSlicer Ironing Wiki
Section 2 — 형상별 결정 트리 (Auto-select)

스킬이 모델 형상을 분석한 뒤 다음 순서로 자동 판정. 모호하면 사용자에게 옵션 제시. 회전체 default가 v1의 random 분산에서 v2의 Auto-select 은닉으로 전환된다.

2.1. 회전체 / 원기둥 / 컵 / 화병 — Auto-select 3단계

회전체 모델 감지
  │
  ├─ 1. spiral_mode 적용 가능? (단일 외벽, top 없음, infill 불필요, 단일 색상)
  │      YES → spiral_mode = 1 (진짜 무 seam, Z축 연속 나선)
  │
  ├─ 2. painted seam 가능한 숨김 면 존재? (뒷면, 내부 홈, 손잡이 그늘, 텍스처)
  │      YES → seam_position = aligned (또는 back)
  │             + scarf external (length 15-20mm, gap 5-10%, height 0-10%, steps 10)
  │             + 사용자가 Studio UI seam paint tool 로 숨김 영역 페인팅
  │
  └─ 3. 위 둘 다 불가 (완전 노출 전방향 원통)
         FALLBACK → seam_position = random + seam_slope_entire_loop = 1
         ※ "은닉"이 아니라 specks 분산 — Real-world Finding 1 컨텍스트
정책 변경 핵심: v1의 random 분산은 "보이지 않게"가 아니라 "흩뿌려 덜 거슬리게"였다. v2는 spiral_mode 또는 painted seam으로 실제 시각적 비노출 면에 숨긴다. 분산 fallback은 painted 적용 불가한 완전 노출 원통 한정.

2.2 ~ 2.6. 박스 · 유기적 · 얇은 벽 · 평면 top · spiral vase

2.2
박스 / 직육면체

back 또는 aligned + corner painted

Sharp corner에 seam 숨김 + 필요 시 painted seam으로 코너 강조. scarf는 일반적으로 off 또는 length 5-8mm (corner sharpness 보존). random 금지 — 평평한 면에 specks 분산되면 외관 ↓.

유기적 곡면 / 피규어

Studio UI seam paint로 후면, 주름, 접합부, 머리카락 텍스처에 페인팅. scarf: Contour (외벽만), length 10-15mm, gap 5-10%, height 0-10%, steps 10. Smart scarf 각도 판정 흔들리면 Off 고려.

2.4
얇은 벽 / 미세 디테일

scarf 짧게 또는 off

seam_position aligned + scarf length 5-10mm 또는 off (scarf ramp가 얇은 벽 형상 침범). wall_loops 1-2 + Arachne wall generator 검토. 작은 홀에 Contour and Hole 비추 — 내경 치수 영향.

2.5
평면 top 강조 (도구 · 케이스 lid · 박스 top)

top 품질 우선 + ironing 적극

seam은 후면/코너에 숨김. Top surface 품질이 외벽보다 더 중요 — outer 속도보다 top 속도/flow에 집중. Ironing 적극 적용 (§5). top_surface_pattern은 monotonicline 또는 원형이면 concentric 실험.

Section 6 — 트레이드오프

Surface-first 모드를 켜면 발생하는 비용. 모든 사용자에게 사전 고지 필수. 속도 무시는 명시 요구지만 너무 느린 PETG/PC/ABS의 부작용은 별도 관리.

6.1 표면 vs 치수

코너 sharpness · 홀 내경 영향

낮은 outer speed + scarf + ironing + flow 조정은 외관 ↑하지만 sharp corner / edge sharpness 흐려짐, 작은 hole 내경 영향 (Contour and Hole 켜면 더 심함). 얇은 벽에서 wall 3-4겹 적용 시 형상 깨짐.
6.2 표면 vs 강도

벽 접합 · overhang 안정성 변화

inner-outer-inner wall sequence는 외관 ↑하지만 일부 형상에서 벽 접합/overhang 안정성 변화. scarf ramp 구간은 layer 강도 미세 변화. 낮은 cooling fan은 광택 ↑하지만 PLA 층간 접착 ↓ 가능.
6.3 표면 vs 실패 확률

blob · drag · clog · heat creep

PETG / PC / TPU ironing은 blob, drag mark, clog / heat creep 위험 ↑. Smart scarf가 angle/overhang에서 끊기면 표면 불균일 — Off 또는 threshold 낮춤 필요. PA-CF / PAHT-CF의 0.4mm hardened nozzle은 0.6mm 권장 소재에서 막힘 위험.
6.4 표면 vs 시간 / 소재

2~4배 시간 + wall/shell ↑

출력 시간 2~4배 (예: 4시간 → 12시간). top_shell 7-9 layers, wall 3-4, calibration coupons → 소재 소모 ↑. 사용자가 시간/소재 비용을 수용하는지 사전 확인.
6.5 속도 무시 시 부작용

열 축적 · warping · stringing 누적

너무 느린 PETG / PC / ABS: 열 축적 → warping, 광택 불균일, stringing 누적 시간 ↑. 외벽 50mm/s 미만에서 chamber 온도 관리 필수 (특히 ABS/ASA enclosure). 0.04mm 같은 극단적 fine layer는 nozzle ooze 누적 → blob 위험 ↑.

Gotchas 체크리스트

  • ✓회전체 default가 v2 surface-first 모드에서 random(분산)에서 Auto-select(은닉)로 전환되었는지 확인. random fallback은 painted 불가한 완전 노출 원통 한정.
  • ✓PETG HF + entire_loop 콤보 사용 시 AMS HT 65°C 8h 사전 건조 + continuous drying 필수. 건조 부족 + 낮은 outer speed는 stringing/blob 폭발.
  • ✓Ironing은 PLA Basic/Matte + 평면 top 한정 적극 권장. PETG/PC/CF류/TPU는 blob/clog/drag 위험으로 비추.
  • ✓spiral_mode 적용 시 normalize가 wall_loops=1, top_shell_layers=0, sparse_infill_density=0를 강제. 다중 외벽/top/infill 필요 모델은 spiral 불가.
  • ✓Smart scarf가 angle 임계에서 끊겨 표면 불균일 발생 시 scarf_angle_threshold ↓ 또는 Smart Off (1.10.1 hotfix 이력 참조).
  • ✓출력 시간 일반 대비 2~4배 증가 — 사용자 사전 고지 필수.
  • ✓매끈한 표면 TOP 3 소재 (PLA Matte / Basic / ABS·ASA) 우선 권장. PA-CF는 fiber 질감으로 매끈 부적합.
  • ✓(2026-08-13) layer_height 1 차값은 0.12. 0.08 은 H2S 공식 process 프로파일 근거가 [미확인] 인 비공식 영역 — 레이어 수 배수를 고지하고 사용자 선택을 받은 뒤에만 내린다. 자동으로 밀어넣지 마라.
  • ✓(2026-08-13) enable_arc_fitting 은 표면 품질 카드가 아니다. G-code encoding 변경(직선 → arc)이며 firmware arc segmentation 리스크가 따라온다. 기본값을 유지하고 곡면 계단 대응으로 제시하지 마라.
  • ✓(2026-08-13) resolution 은 XY 세그먼트 해상도 전용이다. Z 계단(stair-stepping)의 주 해결책이 아니다 — Z 는 layer_height 로만 대응한다.
  • ✓실측 실패 보고가 들어오면 이 페이지가 아니라 Failure Recipes 로 진입한다. 재현 6 축 대조 → L3 → L2 → L1 순서. 사전 권장값을 실패 대응으로 재적용하지 마라.
