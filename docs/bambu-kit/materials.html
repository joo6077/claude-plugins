비슷한 소재 트레이드오프

자주 헷갈리는 5쌍의 트레이드오프 요약. 추천 시 사용자 의도(외관/내열/속도/멀티컬러)에 맞춰 분기.

PLA Matte vs PETG Translucent

PLA Matte — 외관·쉬운 출력 ↑, 내열·내충격 ↓

PETG Translucent — 질김·내열 ↑, 투명감 위해 MVS 6 필수, 표면 튜닝 민감

PETG HF vs ABS / ASA

PETG HF — 냄새/수축 ↓, 실사용 부품 기본값으로 적합

ABS / ASA — 내열·후가공·내후성 ↑, 챔버 45-60°C + 환기 사실상 필수

PAHT-CF vs PA6-CF

PAHT-CF — 저흡습·안정성 ↑, 추천 기본값

PA6-CF — 강도·인성 ↑, 흡습 관리 빡빡 (80-100°C 건조)

PPA-CF / PPS-CF vs PAHT-CF

PPA / PPS-CF — 고내열 최상위, 건조 온도·AMS 경로 제약 큼 → "필요할 때만"

PAHT-CF — 범용 엔지니어링은 더 현실적

TPU 95A HF vs TPU for AMS

TPU 95A HF — 더 TPU답고 빠름(MVS 12), 외부 스풀 전제, AMS 직접 로드 불가

TPU for AMS — Shore 68D 베이스로 강성 ↑, 멀티컬러/AMS 워크플로 우선이면 유일 선택

Gotchas — 카탈로그 사용 시 반복 실수

스킬이 base profile을 추천하기 전에 반드시 거르는 7가지 체크.

  • !AMS HT 사전 건조 필수 — PETG/TPU/ABS/ASA/PC/PA 계열은 출력 시작 전 65°C 사전 건조 사이클 1회. 흡습이 stringing/표면결함의 가장 큰 단일 원인.
  • !CF/GF 류는 hardened 노즐 — PLA-CF / PETG-CF / PAHT-CF / PA6-GF / PET-CF / PPA-CF / PPS-CF / ASA-CF / ABS-GF는 H2S 0.4/0.6 hardened steel hotend 필수. SS 노즐에서 50-200h 내 마모.
  • !PETG HF + entire_loop stringing 위험 — 검증된 실측 신호. retraction/wipe 튜닝 필요. 형상이 stringing-prone하면 PETG Basic으로 fallback 추천.
  • !외부 스풀 필요 SKU 4종 — PET-CF / PPA-CF / PPS-CF / TPU 95A HF는 AMS 2 Pro 직접 로드 불가. 추천 시 외부 스풀 + AMS HT bypass 안내 동반.
  • !멀티컬러는 같은 base 공유 권장 — AMS 듀얼/멀티 출력 시 서로 다른 base(PLA Basic + PLA Silk 등)를 섞으면 retract 시간/온도 차이로 실패. 같은 base의 다른 색을 우선.
  • !PA-CF는 단종 — PAHT-CF로 대체. Studio 프로파일은 남아 있지만 신규 추천에 사용 금지. PAHT-CF는 저흡습 PA12-CF로 사실상 상위 호환.
  • !TPU 85A는 sealing/gasket 부적합 — 검증된 실측 신호. 90A로 한 단계 올리는 것이 해법. 멀티컬러 필요 시 TPU for AMS.
미해결 / 추가 검증 필요

현재 카탈로그에 반영하지 못한 항목 4가지. 다음 사이클 검증 대상.

1

PLA Pure (Studio 2.7.0 Beta)

2026-05-14 Bambu Studio 2.7.0 Public Beta에 신규 프리셋. 2.6.0 stable에는 미포함이라 자동 추천/inherits 대상으로는 보류 안전. stable 승격 후 카탈로그 추가.

→ Bambu Studio Releases
2

PA-CF 단종 (PAHT-CF로 통합)

PAHT-CF 스토어 페이지에 PA-CF가 discontinued라고 명시. Studio에는 base가 남아 있지만 신규 추천은 PAHT-CF로. inherits 대상에서 PA-CF 제외 처리.

→ PAHT-CF SKU
3

AMS 2 Pro 직접 로드 제약 (CF/PPS/PPA + TPU HF)

공식 표는 PLA·PETG·ABS·ASA·PET·PA·PC·PVA·BVOH·PP·POM·HIPS와 Bambu PLA-CF/PAHT-CF/PETG-CF/Support for PLA/PETG/TPU for AMS 지원. PET-CF/PPA-CF/PPS-CF/TPU 95A HF는 외부 스풀 또는 AMS HT bypass 권장.

→ AMS 2 Pro 호환 목록
4

챔버 값 (TDS 권장 + H2S 65°C 분류)

Bambu Studio H2S filament JSON은 챔버 목표값을 행별 명시하지 않는다. 카탈로그의 챔버 범위(45-60°C, 50-65°C 등)는 TDS 권장 + H2S 65°C active chamber 스펙 기반 분류로 추정값.

→ H2S 공식 스펙
