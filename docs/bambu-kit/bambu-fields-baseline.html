04 — 필수 메타필드 (silent skip 회피)

이 7개 메타필드 중 하나라도 누락 / 오타 / 케이스 불일치면 Bambu Studio는 에러 없이 조용히 무시한다. 자동 생성 스킬은 모든 필드를 명시적으로 검증해야 한다.

필드타입필수값silent skip 트리거
version semver string "2.6.0.x" (4-part) 3-part semver("2.6.0") → loader가 거부
type literal string "process" · "filament" 대문자 / 다른 값 → preset 등록 실패
name unique string system preset과 중복 금지 중복 → 시스템 preset이 우선, 사용자 JSON 무시
from literal string "User" (capital U) "user" · "USER" · 누락 → silent skip
inherits preset name string system preset 이름 정확 일치 오타 / 공백 / @ 누락 → 부모 못 찾음, skip
filament_settings_id string array filament JSON에서 필수, 보통 [name] scalar string → array 파싱 실패, skip
compatible_printers string array machine 이름 정확 일치 이름 mismatch → printer에 노출 안 됨

05 — inherits 체인 / 검색 절차

inherits는 부모 프리셋명. 저장 시 부모와 다른 키만 JSON에 저장되고, 로딩 시 부모 config 적용 후 child config가 apply된다. 체인은 "사용자 → vendor variant → vendor base → category common → universal common" 순으로 깊어진다.

Process 체인

사용자 preset
└→0.20mm Standard @BBL H2S
└→fdm_process_single_0.20
└→fdm_process_single_common
└→fdm_process_common

사용자 preset은 4단계 위 vendor variant만 inherits 한다. 그 위 단계는 vendor가 관리.

Filament 체인 (PLA Basic)

사용자 preset
└→Bambu PLA Basic @BBL H2S
└→Bambu PLA Basic @base
└→fdm_filament_pla
└→fdm_filament_common

@BBL H2S variant이 H2S 압출/풀링/온도 보정값을 갖는다.

시스템 preset 검색 절차 (shell)

사용자가 inherits 대상 이름을 모를 때, GitHub raw에서 vendor preset을 직접 검색하는 절차.

# 1. 안정판 tag 확인
curl -s https://api.github.com/repos/bambulab/BambuStudio/releases/latest \
  | jq -r '.tag_name'

# 2. 특정 machine variant의 process preset 목록 (H2S 0.4mm)
curl -s https://api.github.com/repos/bambulab/BambuStudio/contents/resources/profiles/BBL/process \
  | jq -r '.[].name' \
  | grep '@BBL H2S'

# 3. 특정 preset 내용 조회
PRESET="0.20mm Standard @BBL H2S.json"
ENC=$(python3 -c "import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))" "$PRESET")
curl -s "https://raw.githubusercontent.com/bambulab/BambuStudio/master/resources/profiles/BBL/process/$ENC" \
  | jq '.inherits, .compatible_printers, .name'

# 4. inherits 체인 재귀 추적
PARENT=$(curl -s ".../$ENC" | jq -r '.inherits')
while [ "$PARENT" != "null" ] && [ -n "$PARENT" ]; do
  echo "→ $PARENT"
  # grep 으로 process/filament 폴더에서 $PARENT.json 위치 찾기
  # 다음 부모로 이동
done
! 주의: master는 안정판 이후 142+ commits이 진행 중이다. 안정판과 정확히 동일한 preset이 필요하면 git checkout v02.06.00.51 후 로컬에서 추출하거나, releases 페이지에 첨부된 source asset을 사용한다.

07 — inherits vs 전체 필드 명시

자동 생성 스킬은 inherits 기반을 기본값으로 사용한다. 재현성 엄격 시점이거나 호스트 Studio 버전을 통제할 수 없을 때만 전체 명시.

inherits 기반 (권장)

  • ✓장점 — Bambu 공식 H2S/AMS/노즐/펌웨어 업데이트 자동 반영
  • ✓장점 — JSON이 작고 schema 변경에 덜 취약
  • ·단점 — 부모 업데이트 시 결과가 미세하게 변경 가능
  • ·단점 — 재현성 엄격 시 생성 시점 부모 버전 별도 기록 필요

전체 필드 명시

  • ✓장점 — 생성 당시 동작 고정, 독립 실행형 프리셋
  • ·단점 — v2.x schema 변화를 직접 추적해야 함
  • ·단점 — H2S variant 배열, AMS HT/2 Pro 필드 변화 직접 대응
  • ·단점 — outdated 키 섞일 위험 (예: scarf_seam_type)

10 — Gotchas 체크리스트

이 항목들은 Bambu Studio가 에러를 띄우지 않고 silent로 처리하는 케이스다. 자동 생성 스킬은 출력 직전 모두 검증해야 한다.

  • ✓Capitalize "User" — from은 "User" (capital U). "user"는 silent skip.
  • ✓filament_settings_id는 array — ["name"] 형태. scalar string으로 두면 파싱 실패.
  • ✓compatible_printers는 H2S 정확 매칭 — "Bambu Lab H2S 0.4 nozzle". 공백 / 대소문자 / nozzle 표기 불일치 시 printer에 노출 안 됨.
  • ✓version은 4-part semver — "2.6.0.51". "2.6.0" 같은 3-part는 loader가 거부.
  • ✓inherits는 system preset 이름 정확 일치 — @BBL H2S suffix까지 1글자도 다르면 부모 못 찾음.
  • ✓filament 측 키는 모두 filament_* prefix — scarf_seam_type, scarf_start_height 등은 outdated 가이드일 가능성 높음.
  • ✓variant array 길이 매칭 — H2S Standard / High Flow 등 variant가 있으면 부모 키 길이를 그대로 따라간다.
  • ✓scarf 활성화 조건 — seam_slope_type ≠ none AND seam_slope_min_length > 0 둘 다 만족.
  • ✓process scarf vs filament scarf 우선순위 — override_filament_scarf_seam_setting=1이면 process의 seam_slope_*가 우선 적용 (소스/UI 명칭 추론).
  • ✓master ≠ 안정판 — 142+ commits 진행 중. 정확한 baseline은 v02.06.00.51 tag 추출 권장.
  • ✓AMS 표기 — "AMS Pro 2"가 아니라 AMS 2 Pro가 공식.
  • ✓(v3) adaptive_layer_height 를 process JSON 에 넣지 마라 — option 정의 주석 처리 + legacy ignore set. 켜진다는 근거가 없고 Phase 4.3 게이트가 잔존을 FAIL 처리한다 (§9.1 · §9.4).
  • ✓(v3) layer_height 1 차값은 0.12 — 0.08 은 min_layer_height 0.07 하한 위라는 것만 확인된 비공식 영역이고 H2S 공식 process 프로파일 근거는 [미확인].
  • ✓(v3) resolution 은 XY 세그먼트 해상도 전용 — Z 계단 해결책이 아니다. enable_arc_fitting 도 품질 기능이 아니라 G-code encoding 변경이다.
  • ✓(v3) filament 의 "nil" 은 미설정이 아니라 위임 — 임의 숫자로 채우면 printer / extruder 기본 튜닝을 통째로 덮어쓴다 (§9.2).
  • ✓(v3) plate 온도는 plate-specific 키로만 — bed_temperature_initial_layer 는 obsolete ignored key, bed_temperature 도 게이트 금지 목록 (§9.3 · §9.4).
  • ✓(v3) 철자는 elefant_foot_compensation — Bambu 의 의도적 오타다. elephant_... 는 silent skip 된다.
  • ✓(v3) 수치를 Failure Recipes 와 중복 기재하지 마라 — 키 이름 · 단위 · default 는 이 페이지 §09 가 정본이고, 판정 절차 · 게이트 · 부작용은 Failure Recipes 가 갖는다.
