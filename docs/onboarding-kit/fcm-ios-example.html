Step 1 — Apple Developer에서 App ID에 Push 활성화
01
Explicit App ID 등록
출처: Apple Developer Help — Account · 조회 2026-07-27, 재확인 2026-08-13
어디서
Developer Account → Certificates, Identifiers & Profiles → Identifiers
무엇을
  1. + → App IDs → Continue
  2. App ID Type: Explicit 선택. Wildcard는 Push에 사용 불가
  3. Description과 Bundle ID 입력
  4. Push Notifications 체크
  5. Continue → Register
Bundle ID 변경 정책. App Store Connect에 빌드를 한 번이라도 올린 뒤에는 변경할 수 없습니다. 출시 후에는 새 App ID, Firebase iOS 앱, Profile을 다시 구성합니다. 테스트 단계에서는 교체할 수 있습니다.
확인
Identifiers 상세에 Push Notifications 활성 표시
Step 2 — APNs Authentication Key (.p8) 발급
02
APNs 인증 키 생성
출처: Apple Account Keys(2026-07-27) + Firebase FCM Flutter(2026-08-13)
현행 방식. 갱신 불필요하고 Team 앱에 공유 가능한 .p8 흐름만 다룹니다. .p12의 상태를 출처보다 강하게 판단하지 않습니다.
무엇을
  1. Keys → + → Key Name
  2. Apple Push Notification service → Configure
  3. Environment 선택. 하나로 dev/prod를 쓰려면 Sandbox & Production
  4. Team Scoped (All Topics) 또는 Topic Specific
  5. Save → Continue → Register → Download
  6. 10자리 Key ID와 Membership의 10자리 Team ID 기록
보안. .p8은 단 한 번만 다운로드됩니다. 비밀 저장소에 두고 git에 커밋하지 마세요. 분실하면 revoke 후 재발급합니다.

Step 7 — Dart 초기화 · 권한 요청 · 토큰 획득
07
Dart 전용 초기화와 리스너
출처: FCM Flutter(2026-08-13) + FlutterFire 설정(2026-07-27)
네이티브 소스를 건드리지 않습니다. 네이티브 초기화는 firebase_core가 담당합니다.

7-1. Dart 초기화 (main.dart)

import 'package:flutter/material.dart';
import 'package:firebase_core/firebase_core.dart';
import 'package:firebase_messaging/firebase_messaging.dart';
import 'firebase_options.dart';

@pragma('vm:entry-point')
Future<void> _firebaseMessagingBackgroundHandler(RemoteMessage message) async {
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  debugPrint('Background message: ${message.messageId}');
}

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  FirebaseMessaging.onBackgroundMessage(_firebaseMessagingBackgroundHandler);
  runApp(const MyApp());
}

7-2. 권한 요청 + 토큰 획득 + 메시지 리스너

Future<void> setupFcm() async {
  final messaging = FirebaseMessaging.instance;
  final settings = await messaging.requestPermission(
    alert: true,
    badge: true,
    sound: true,
  );
  if (settings.authorizationStatus == AuthorizationStatus.authorized ||
      settings.authorizationStatus == AuthorizationStatus.provisional) {
    final token = await messaging.getToken();
    debugPrint('FCM token: $token');
    // TODO: 서버에 token 저장
    messaging.onTokenRefresh.listen((newToken) {
      // TODO: 서버에 새 토큰 업데이트
    });
  }
  await messaging.setForegroundNotificationPresentationOptions(
    alert: true,
    badge: true,
    sound: true,
  );
  FirebaseMessaging.onMessage.listen((RemoteMessage message) {
    debugPrint('Foreground: ${message.notification?.title}');
  });
  FirebaseMessaging.onMessageOpenedApp.listen((RemoteMessage message) {
    debugPrint('App opened from notification: ${message.data}');
  });
}
